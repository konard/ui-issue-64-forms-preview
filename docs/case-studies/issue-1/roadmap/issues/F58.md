## Context

https://github.com/konard/konard.github.io is a personal site and the testbed
for a configurable UI. Its issue konard/konard.github.io#39 says it will become our own UI
framework. That framework is this repository. The facts below come from the
[research](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/konard-github-io-and-links-visuals.md).

The site is a React 19 + Vite 8 multi-page app. It uses d3-force,
`@fontsource` fonts, Vitest and per-issue Playwright suites on Chromium,
Firefox and WebKit. It requires Node 24 or later. It has these problems:

- **No licence.** There is no LICENSE file, and the GitHub API reports
  `license: null`. No code may be copied into this public-domain framework
  until the owner adds one.
- **Regex parsing.** `src/links/edit.js` parses Links Notation with the regex
  `/\(\s*(?:(\d+)\s*:)?\s*(\d+)[\s,]+(\d+)\s*\)/g`. `links-notation` is not
  imported anywhere in `src/`.
- **JSON settings.** Settings are stored as JSON in localStorage `settings`
  and `settings-presets`, and shared through the `#settings=` hash.
- **Hard-coded strings.** English and Russian text is hard-coded as `{en, ru}`
  objects inside components, including `NetworkEditor.jsx`.
- **Large generated CSS.** `src/skins.frames.js` generates `skins.frames.css`,
  which is 1,067 lines and about 84 KB.
- **Open issue konard/konard.github.io#47.** The top-left corner and the top and bottom edges are
  not transparent by default:
  https://github.com/konard/konard.github.io/issues/47
- **Ad hoc migrations** such as `before45()`.

This issue is filed here, but the main deliverable is a pull request in
konard/konard.github.io. Any missing framework piece becomes a new issue in
link-foundation/ui.

## Goal

konard.github.io renders its settings, controls, network editor and dev
overlay with framework packages. It stores settings as LiNo, reads the old
JSON, and deletes its own copies of the settings engine, controls, regex
parser and frame generator. It looks the same before and after, except for
the konard/konard.github.io#47 fix.

### Out of scope

- Content pages (CV, blog, research), data charts (`ContributionsChart`,
  `LanguagesChart` and others), canvas backgrounds and the sound engine. They
  are only re-themed, not rewritten.
- Reducing the 372 MB repository size.

## Dependencies

- **Prerequisite (not a roadmap issue):** the repository owner adds a licence
  file, preferably Unlicense like immortality and links-visuals. Until then:
  - do not copy code from it into link-foundation/ui;
  - the migration pull request may only replace site code with framework
    code.
- **Blocked by {{F34}}**: the network view (layouts, interaction, worker)
  that replaces `render.js`, `placement.js` and the collision solver.
- **Blocked by {{F37}}**: the settings panel generated from the schema, which
  replaces `SettingsPage.jsx` and the controls.
- **Blocked by {{F46}}**: the dev-mode inspector. The site is the first real
  host, which is why R9 points here.
- **Related:** {{F57}} (playbook and checklist), {{F15}}, {{F13}}, {{F43}},
  {{F47}}, {{F59}} (shared link renderer), {{F64}} (shared settings schema
  and sound engine).

## Step-by-step plan

1. Confirm the licence prerequisite. Link the LICENSE commit in the pull
   request.
2. Copy `docs/migration/checklist-template.md` from {{F57}} into the pull
   request description.
3. **Freeze the contracts** with Vitest tests in `src/settings/contracts.test.js`:
   - localStorage keys `settings` and `settings-presets`;
   - `#settings=<urlencoded JSON>` links (`shareLink`, `lookOfHash`) and the
     "Before the link" preset;
   - `--section-key` CSS variables and `data-section-key` attributes;
   - the before-paint `SETTINGS_SCRIPT` injected by the `themeBeforePaint`
     Vite plugin;
   - `/network/?code=…` URLs, with default `11 22 12`.
4. **Take baseline screenshots** with Playwright on Chromium, Firefox and
   WebKit. Cover:
   - `/`, `/settings/`, `/network/?code=11%2022%2012` and `/art/#symbols`;
   - presets "Matrix universe", "calm" and "Light and fast";
   - light and dark modes;
   - 1280×800 and 390×844.

   Store them in `experiments/framework-migration/baseline/`.

5. **Schema to LiNo.** Generate `src/settings/schema.lino` from the about 114
   field-factory calls with a one-off script,
   `experiments/framework-migration/schema-to-lino.mjs`. Example entry:
   `(liquid.blur: (type range) (default 18) (min 0) (max 40) (unit px))`.
   Load it with the {{F15}} engine. `applied.test.js` must still pass.
6. **Settings storage.** Write user diffs as LiNo, for example
   `(liquid.blur 24)`. Keep a reader for the old JSON in localStorage and in
   `#settings=`, and keep `COMFORT` keys local when a shared look is applied.
7. **Parser.** Replace `parseLinks` in `edit.js` with `links-notation`. Keep
   `configurations.js` (code and index maths) as it is.
8. **Controls and panel.** Render `/settings/` with the {{F37}} panel. Delete
   the replaced controls one by one, keeping the APG listbox behaviour and
   the Safari focus fix from `numericKeys.js`.
9. **Network.** Mount the {{F34}} view in `NetworkPage.jsx`. Compare the SVG
   export of 20 codes with the baseline.
10. **Themes.** Move the 12 palettes and the glass, liquid and futuristic
    skins into a theme pack from {{F43}}. Fix konard/konard.github.io#47 in the frame generator, not
    in per-skin CSS.
11. **i18n.** Move the `{en, ru}` literals into {{F13}} catalogs. Keep
    `?lang` and the `plural.js` rules.
12. **Dev mode.** Enable {{F46}} with `?ui-dev`. The "Your changes" diff box
    becomes the overrides document.
13. **Delete** the old files listed under "Files to create or change", then
    record the line counts before and after.

## Acceptance criteria

- [ ] The repository has a LICENSE file before any shared code moves.
- [ ] `contracts.test.js` passes before and after the migration.
- [ ] Old `settings` JSON and old `#settings=` links still load the same look
      (tests).
- [ ] `src/links/edit.js` imports `links-notation`, and
      `grep -n "RegExp\|/g" src/links/edit.js` finds no Links Notation regex.
- [ ] Screenshot diffs against the baseline are below 0.1 % of pixels on all
      three engines, except the konard/konard.github.io#47 corners, which are documented.
- [ ] Issue konard/konard.github.io#47 is fixed: the corners and edges are transparent by default
      (Playwright pixel check).
- [ ] No `{en, ru}` object literals remain in `src/pages/` (grep).
- [ ] `?ui-dev` opens the inspector on `/settings/`.
- [ ] The pull request lists the deleted files and line counts.

with the baseline screenshots.
