# Template history

This repository was created from
[link-foundation/js-ai-driven-development-pipeline-template](https://github.com/link-foundation/js-ai-driven-development-pipeline-template).
The documents in this folder were written for that template, not for
`link-foundation/ui`. **Every issue number in this folder refers to
[the template repository's issues](https://github.com/link-foundation/js-ai-driven-development-pipeline-template/issues)**, not to issues
of this repository.

They were moved here (with `git mv`, so `git log --follow` still shows their
history) by [link-foundation/ui#4](https://github.com/link-foundation/ui/issues/4)
so that `docs/case-studies/issue-N/` can be used only for issue `N` of
`link-foundation/ui`. The content of the moved documents is unchanged.
