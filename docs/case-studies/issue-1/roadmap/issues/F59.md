## Context

[links-visuals](https://github.com/konard/links-visuals) is a lab for drawing
one link, and networks of links, as a single continuous curve. Other links
can point at the middle of a link. The facts below come from the
[research](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/konard-github-io-and-links-visuals.md).

The project uses plain HTML pages with ES modules in `js/`, SVG rendering
with an optional Canvas mode, a Bun `serve.ts` dev server, `node --test`
unit tests and Playwright/browser-commander e2e tests. It is Unlicense, so
code can move into the framework directly.

Problems found:

- **Unpinned CDN.** D3 v7 is loaded at runtime from `https://esm.sh/use-m`
  as `use('d3')`. It does not work offline, is not pinned, and is a
  supply-chain risk.
- **Global state.** `js/state.mjs` holds global singletons, so two views
  cannot share a page.
- **Duplicate renderer.** `js/canvas-render.mjs` re-implements the SVG
  markers and paths by hand.
- **Busy loop.** `js/animation.mjs` runs `requestAnimationFrame` every frame,
  even when idle.
- **Copied CSS.** Inline CSS is copied into every page. Markers are
  hard-coded black.
- **Old experiments.** `failed-attempts/` holds 76 HTML snapshots.

{{F33}} ports the single-link geometry into the framework. This issue
switches links-visuals itself to that package, so the lab page and the
framework stop diverging.

## Goal

Every links-visuals page renders through `@link-foundation/ui-*` packages,
with no runtime CDN. The repository keeps its pages as demos and deletes the
modules that moved into the framework. The pages look and behave the same:
drag, zoom and pan, IK animation, drawing.

## Step-by-step plan

1. Copy the {{F57}} checklist template into the pull request.
2. **Freeze behaviour** with `tests/contracts.test.mjs` (`node --test`):
   - path output of `js/path.mjs` for the 9 fixed points;
   - IK output of `ik-pure.mjs` for 3 targets;
   - zoom maths (factor 0.999^delta, clamped to 0.1–20).

   Save the outputs as JSON fixtures.

3. **Take baseline screenshots** with Playwright of every page in the
   inventory at 1280×800, plus `?debug=zoom`. Store them in
   `experiments/framework-migration/baseline/`. Record the fixed bugs as
   regression tests:
   - konard/links-visuals#1 and konard/links-visuals#3: start-point snapping;
   - konard/links-visuals#15: the infinite grid;
   - konard/links-visuals#19, konard/links-visuals#21: zoom away from the centre;
   - konard/links-visuals#23, konard/links-visuals#28: grid proportions.
4. **Pin D3.** Replace `use('d3')` from esm.sh with a pinned npm dependency
   bundled locally, or drop it where the framework does not need it. After
   this step the pages must work offline (Playwright with network blocked
   except localhost).
5. **Switch `index.html`** to the {{F33}} element. Delete the matching local
   modules only when the step-2 fixtures still match.
6. **Switch the blueprint, IK and draw pages** one at a time, one commit
   each, with screenshot diffs.
7. **Replace `state.mjs`** with per-view instances. Add a test page with two
   independent views on one page.
8. **Stop the idle loop.** `animation.mjs` stops the loop when nothing
   changes. A test counts frames over 2 s idle and expects 0 after settling.
9. **One stylesheet.** Move the inline per-page CSS into one theme file that
   uses framework tokens. Markers take `currentColor`.
10. Delete the moved modules and record the line counts before and after.

## Acceptance criteria

- [ ] `grep -rn "esm.sh\|use-m" .` (excluding `failed-attempts/` and `docs/`)
      returns nothing.
- [ ] All pages load and work with the network blocked except localhost
      (Playwright).
- [ ] `node --test tests/*.test.mjs` passes, and the step-2 fixtures are
      unchanged.
- [ ] Screenshot diffs of every page are below 0.1 % of pixels.
- [ ] Two independent link views work on one test page.
- [ ] No `requestAnimationFrame` callbacks run after 2 s idle (test).
- [ ] The SVG and Canvas modes draw the same markers from one definition
      (pixel diff below 1 %).
- [ ] The pull request lists deleted modules and line counts.

## How to verify

```bash
bun install   # or the package manager the repository uses
node --test tests/*.test.mjs
bun serve.ts &
npx playwright test experiments/framework-migration
grep -rn "esm.sh" --include=*.html --include=*.mjs . | grep -v failed-attempts
```

Expected screenshots: `index.html`, `blueprint.html`, `animated-blueprint.html`
(frame at 1 s), `grid.html` with 64 links, and `draw.html` after a scripted
stroke.
