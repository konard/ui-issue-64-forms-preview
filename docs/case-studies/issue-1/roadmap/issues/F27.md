## Context

Overlays are where our apps break most often. deepcase shows a handler window
above a modal (https://github.com/deep-foundation/deepcase-app/issues/290),
its radial context menu has rotated labels that are hard to read
(https://github.com/deep-foundation/deepcase-app/issues/299), and it fights
the browser context menu
([deepcase.md](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/deepcase.md)
sections 3 and 10). meta-sovereign has its own `menuPlace()` placement maths,
`dialog-focus.js` focus traps and the rules "a context-menu target is distinct
from a multi-selection" and "focus traps in dialogs"
([meta-sovereign-chat.md](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/meta-sovereign-chat.md)
sections 2, 3.4 and 4). immortality has a docked non-modal drawer
(`role=dialog`, `aria-modal=false`, Escape closes, focus returns) and
arrow-key tab groups
([immortality-and-anime-avatar.md](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/immortality-and-anime-avatar.md)
section 6, pattern 16). konard.github.io clamps its popups to the viewport
([konard-github-io-and-links-visuals.md](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/konard-github-io-and-links-visuals.md)
section 4.1).

The research marks Floating UI (MIT) as ADOPT, with the native Popover API and
CSS anchor positioning where available
([existing-solutions.md](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/existing-solutions.md)
section 4).

## Goal

Ship dialog, popover, menu and context menu, tooltip, tabs, toast, drawer and
a radial menu in `@link-foundation/ui-components`, built on the {{F25}}
machines and accessibility helpers, using native `<dialog>` and the Popover
API wherever possible.

## Scope

### In scope

- Kinds: `dialog`, `alert-dialog`, `popover`, `tooltip`, `menu`,
  `menu-item`, `menu-separator`, `context-menu`, `radial-menu`, `tabs`,
  `tab`, `tab-panel`, `toast` (with a `toaster` region), `drawer`.
- A positioning module over `@floating-ui/dom` (`offset`, `flip`, `shift`,
  `autoUpdate`) shared by popover, tooltip, menu and `select` from {{F26}}.
- Use of the top layer: modal dialogs through `showModal()`, popovers,
  menus and tooltips through the `popover` attribute.
- Context menu triggers: right click, the ContextMenu key, Shift+F10 and long
  press on touch; only on elements that declare one.
- Radial menu with horizontal labels and icons, keyboard support and a linear
  fallback.
- Kind entries, machines, token styles, tests and gallery stories for each.

### Out of scope

- Windows, docks and split panes ({{F28}}); this issue only uses its layer
  manager.
- Command palette and keyboard shortcut registry (later issue).
- Animations beyond token-driven CSS transitions ({{F44}}).
- Graph-specific menus of the deepcase migration ({{F62}}).

## Step-by-step plan

1. `src/overlays/position.js`:
   ```js
   /**
    * @param {HTMLElement} anchor  or a virtual element { getBoundingClientRect }
    * @param {HTMLElement} floating
    * @param {{ placement?: string, offset?: number, onUpdate?: (pos) => void }} options
    * @returns {() => void} cleanup from autoUpdate
    */
   export function positionFloating(anchor, floating, options) {}
   ```
   A virtual element at the pointer position is used by context menus.
   CSS anchor positioning may be added as progressive enhancement (check
   current browser support first).
2. `dialog`: native `<dialog>`, `showModal()`, `aria-labelledby` from its
   `title` part, the `cancel` event (Escape) dispatches `(on close ...)`,
   focus returns to the opener. `alert-dialog` adds `role="alertdialog"` and
   no light dismiss. Example:
   ```lino
   (confirm: dialog
     (title 'Delete message?')
     (body (text 'This cannot be undone.'))
     (actions
       (cancel: button (label 'Cancel') (on press (emit close)))
       (delete: button (label 'Delete') (variant filled) (on press (emit delete)))))
   ```
3. `popover` and `tooltip`: `popover="auto"` (light dismiss) for popovers,
   `popover="manual"` for tooltips. The tooltip opens after a delay on hover
   or focus (timers through the {{F25}} injected clock), stays while the
   pointer is over it and closes on Escape (WCAG 1.4.13).
4. `menu` and `context-menu`: APG menu button pattern; arrows, Home/End,
   typeahead, Enter/Space activate, Escape closes and returns focus, one level
   of submenus with ArrowRight/ArrowLeft. `contextmenu` calls
   `preventDefault()` only when the target declares a menu. The menu receives
   the target ID separately from the current selection.
5. `tabs`: APG tabs; roving tabindex, automatic activation by default,
   `(activation manual)` option; `aria-controls` and `aria-labelledby` pairs
   generated from link IDs.
6. `toast` and `toaster`: a queue in a polite live region (`role="status"`),
   `(politeness assertive)` for errors, auto-dismiss duration from a token,
   paused on hover and focus, never moves focus, at most `(max 3)` visible,
   every toast closable (WCAG 2.2.1). `popover="manual"` keeps it on top.
7. `drawer`: `(modal true)` uses `showModal()` with a side placement;
   `(modal false)` is a docked panel with `role="dialog"` and
   `aria-modal="false"`; Escape closes both and focus returns.
8. `radial-menu`: pure geometry in `src/overlays/radial-geometry.js`:
   `radialLayout(count, { radius, startAngle }) -> [{ x, y, angle }]` and
   `sectorAt(dx, dy, count, startAngle) -> index | -1`. Labels are never
   rotated; each item shows an icon and a horizontal label. `role="menu"` with
   `menuitem` children, arrow keys move clockwise/counter-clockwise, Enter
   activates, Escape closes. `(presentation linear)` renders the same items
   as a normal `menu`; choose it automatically when the circle does not fit
   the viewport. Transitions respect `prefers-reduced-motion`. Story example:
   ```lino
   (node-menu: radial-menu
     (radius 108)
     (item editor (label 'Editor') (icon edit) (on select (emit open-editor)))
     (item insert (label 'Insert') (icon plus) (on select (emit insert)))
     (item delete (label 'Delete') (icon trash) (on select (emit delete))))
   ```
9. Register non-top-layer surfaces (docked drawer, toaster fallback) with the
   layer manager.
10. Stories in `packages/ui-components/stories/<kind>.lino` (a menu story uses
    the Telegram Desktop message menu set: Reply, Quote and Reply, Edit, Pin,
    Copy, Forward, Delete, Select), catalog entries in
    `src/overlays/catalog.lino`, gallery page `e2e/pages/overlays.html`.

Suggested pull requests: A popover, tooltip, dialog, drawer; B menu, context
menu, radial menu; C tabs, toast.

## Acceptance criteria

- [ ] `radial-geometry.test.js`: positions for 1, 3 and 11 items, sector
      hit tests at the boundaries, and no label transform contains `rotate`.
- [ ] `position.test.js` (with a stubbed `computePosition`): cleanup stops
      `autoUpdate`; a virtual anchor is supported.
- [ ] `dialog`: e2e test shows focus inside on open, Tab cycles inside,
      Escape closes, focus returns to the opener, background is inert.
- [ ] A {{F28}} window raised while a modal dialog is open stays visually
      below it (e2e reproduction of deepcase-app issue 290).
- [ ] `menu` and `context-menu`: keyboard-only e2e (Shift+F10, arrows,
      typeahead, Escape); right click outside declared targets keeps the
      browser menu; the handler receives the target ID, not the selection.
- [ ] `tooltip` stays open while hovered and closes on Escape (e2e).
- [ ] `tabs`: arrows move focus; manual mode activates only on Enter/Space.
- [ ] `toast`: announced through the live region, never takes focus, pauses
      on hover, closes with its close button (e2e).
- [ ] `radial-menu`: keyboard-only e2e, and the linear fallback is used in a
      320 px wide viewport.
- [ ] `expectAccessible(page)` reports no violations on `overlays.html` in
      each opened state; `screenshotMatrix` baselines (light, dark) committed.
- [ ] `npm test`, `npm run lint`, `npm run format:check`,
      `npm run check:duplication` pass; `@floating-ui/dom` is MIT.
