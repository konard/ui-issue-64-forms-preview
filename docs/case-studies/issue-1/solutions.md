# Issue 1 — Solutions per requirement

For every requirement in [`requirements.md`](requirements.md), this file lists:

- the chosen solution;
- the alternatives that were considered;
- the existing components and libraries that solve the problem, or part of it;
- the roadmap issues that deliver it. Their keys are listed in
  [`roadmap/README.md`](roadmap/README.md), and the GitHub issue numbers are in
  [`../../ROADMAP.md`](../../ROADMAP.md).

The libraries are assessed in detail (licence, maintenance, fit) in
[`research/existing-solutions.md`](research/existing-solutions.md). The Links
Notation facts come from
[`research/links-notation-ecosystem.md`](research/links-notation-ecosystem.md).

Licence policy for every row: we may depend on MIT, ISC, BSD, Apache-2.0, CC0
and CC-BY (with attribution). EPL code is allowed only in optional plugins.
GPL, AGPL, non-commercial and "source available" code is used only as a
design reference, never as a dependency.
