## Context

After {{F06}} every leaf value of a UI document is a plain string: `16px`,
`150ms`, `'#6750A4'`, `true` and `filled` all look alike. Renderers, the token
exporters ({{F11}}) and the style engine ({{F12}}) need typed values. The
research in
[links-notation-ecosystem.md](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/links-notation-ecosystem.md)
(section 5, "typed values") found:

- The official parser does not record whether a reference was quoted:
  `'x'`, `"1"` and `1` all produce the same `id` string. So the codec rule of
  [`lino-objects-codec`](https://www.npmjs.com/package/lino-objects-codec)
  (0.9.4: bare = number/bool/null, quoted = string) can only be applied with
  that package's own reader.
- Recommended approach: **schema-driven typing** (the schema of a kind says
  `gap` is a dimension), with lexical inference only as a fallback.
- Units are written bare (`8px 0.2s 50% 1.5rem`); hex colours must be quoted
  (`'#6750A4'`), because a bare `#` starts a comment in `links-notation`
  0.27.1 (`(a #6750A4)` is a syntax error); wide-gamut colours are links:
  `(oklch 0.62 0.19 255)`.
- `:` must not appear in bare values; structured links are used instead.
- References: the samples use `(token color.primary)`; the research also
  proposes the sigils `@color.primary` and `$param`. The dialect spec
  {{F03}} (`docs/spec/values.md`) makes the structured forms canonical in v0 —
  `(token color.primary)`, `(param draft.text)`, an element id as a bare
  reference, fallbacks `(or (token a) (token b) 8px)` — and **reserves** `@`
  and `$`: a value starting with them gives the diagnostic `reserved-sigil`.

## Goal

`@link-foundation/ui-core` exports a value layer that turns raw strings and
nested links into typed values using a LiNo schema, formats them back to
canonical LiNo, and converts them to CSS text.

## Scope

### In scope

- The value types of `docs/spec/values.md`: `string`, `number` (`-1`,
  `1.5e3`), `dimension` (`px`, `rem`, `em`, `%`, `vw`, `vh`), `duration`
  (`ms`, `s`), `color` (quoted hex `'#6750A4'`/`'#6750A4CC'`,
  `(rgb 103 80 164)`, `(oklch 0.6 0.2 300)`), `enum`, `token-ref`
  (`(token a.b)`), `element-ref` (bare id), `action`; plus `param`
  (`(param a.b)`) and `fallback` (`(or ...)`). If the spec adds `boolean` or
  `integer` (needed for `disabled`), implement them too; otherwise raise it in
  `docs/spec/open-questions.md`.
- Property types come from the vocabulary `docs/spec/vocabulary.lino` of
  {{F03}} (for example `(property variant (enum filled outlined text))`);
  `typeNode(node, vocabulary)`.
- `inferValue(raw)` fallback for properties the vocabulary does not declare
  (quoting is lost by the parser, so inference is lexical only).
- `formatValue(v)` (canonical LiNo) and `toCss(v)` (CSS text; refs become
  `var(--color-primary)` by default).
- oklch ⇄ sRGB conversion for exporters that need hex ({{F11}}).

### Out of scope

- Resolving references against a token set ({{F11}}, {{F12}}).
- Writing vocabulary entries for new kinds (each control issue adds its own,
  for example {{F26}}); sigil shorthands (reserved in v0).
- Changing the upstream parser (only propose it, see step 9).

## Dependencies

- {{F06}} (blocker): `UiNode`, `UiProperty`, `loadVocabulary` and `parse`.
  Consumed: raw values (`string` atoms and arrays for nested links) to type.
  Until F06 merges, test against hand-written `UiNode` objects.
- Indirect: {{F03}} (`values.md`, `vocabulary.lino`, `fixtures/values/` and
  `fixtures/references/`, which this issue must pass).
- Related: {{F11}} and {{F12}} (main consumers), {{F15}} (settings schemas reuse
  the same value types), {{F26}}.

## Step-by-step plan

1. Read property types from `docs/spec/vocabulary.lino` through
   `loadVocabulary` of {{F06}} (do not write another reader). Entries look
   like (sketch from {{F03}}):
   ```lino
   (button: kind
     (positional label)
     (property label string)
     (property variant (enum filled outlined text))
     (property on action multi)
     (children none))
   ```
   Defaults, if the spec has none yet, may be added as `(default VALUE)` in a
   property link — agree it in the spec first.
2. `src/values/types.js` — JSDoc union:
   ```js
   /** @typedef {{ type: 'dimension', value: number, unit: 'px'|'rem'|'em'|'%'|'vw'|'vh' }
    *   | { type: 'duration', value: number, unit: 'ms'|'s' }
    *   | { type: 'color', space: 'srgb', r: number, g: number, b: number, a: number }
    *   | { type: 'color', space: 'oklch', l: number, c: number, h: number, a: number }
    *   | { type: 'token-ref', path: string } | { type: 'element-ref', id: string }
    *   | { type: 'param', path: string } | { type: 'action', name: string, args: unknown[] }
    *   | { type: 'fallback', options: TypedValue[] }
    *   | { type: 'string'|'enum', value: string } | { type: 'number', value: number }
    *   | { type: 'boolean', value: boolean } | { type: 'list', items: TypedValue[] }} TypedValue */
   ```
3. `src/values/scalars.js`: number and unit splitting with a small
   hand-written character scanner over a single token string (this reads a
   token, not LiNo structure). `16px` → `{ type: 'dimension', value: 16, unit: 'px' }`.
4. `src/values/color.js`: `parseColor(raw)`, `formatColor(c)`,
   `oklchToSrgb(c)`, `srgbToOklch(c)`, `toHex(c)` (gamut: clamp each channel
   to 0..1). Use the OKLab matrices published by Björn Ottosson
   (https://bottosson.github.io/posts/oklab/) or the `culori` package (MIT,
   4.0.2 at planning time) — record the choice in the README.
5. `src/values/refs.js`: `(token color.primary)` gives
   `{ type: 'token-ref', path: 'color.primary' }`; `(param draft.text)` gives a
   `param`; `(or (token a) 8px)` gives a `fallback`; a bare `@x` or `$x`
   gives the diagnostic `reserved-sigil` (the parser accepts them as plain
   references, verified with `links-notation` 0.27.1).
6. `src/values/typed.js`: `typeValue(raw, spec) → { value, diagnostics }`;
   `typeNode(node, schemaSet) → TypedUiNode` (adds `typed` next to `values`);
   unknown props and wrong values become diagnostics
   (`{ code: 'invalid-value', id, prop, expected }`), never exceptions.
7. `src/values/infer.js`: `inferValue(raw)`: numeric → number, number+known
   unit → dimension/duration, `#hex` → color, `(token ...)` → token-ref,
   `(param ...)` → param, `(oklch ...)`/`(rgb ...)` → color, otherwise string.
8. `src/values/format.js`: `formatValue(v)` (hex colours always quoted:
   `'#6750A4'`; refs printed as `(token a.b)`) and `toCss(v, { refToVar })`
   (a token ref becomes `var(--color-primary)` by default).
9. Prepare an upstream issue for a `quoted` flag on parsed references (so the
   codec rule works with the official parser). Put the draft text in the pull
   request description and link it as a URL to file:
   https://github.com/link-foundation/links-notation/issues/new?title=Expose+whether+a+reference+was+quoted+in+parsed+Link+objects
   Do not create the issue yourself.
10. Export everything from `src/index.js` under `values` and add types to
    `src/index.d.ts`; document the table of types in the README.

## Acceptance criteria

- [ ] `typeValue('16px', { type: 'dimension' })` deep-equals
      `{ type: 'dimension', value: 16, unit: 'px' }`; `150ms` and `0.2s` give
      durations; `'1.5rem'` and `50%` work.
- [ ] `samples/tokens.lino` values type as: `'#6750A4'` colour, `16px`
      dimension, `150ms` duration.
- [ ] `(oklch 0.62 0.19 255)` parses; `srgbToOklch(oklchToSrgb(c))` is within
      0.001 per channel for 20 in-gamut colours; `toHex` of
      `{ space: 'srgb', r: 1, g: 1, b: 1, a: 1 }` is `#FFFFFF`.
- [ ] `(token color.primary)` gives `{ type: 'token-ref', path: 'color.primary' }`
      and `toCss` gives `var(--color-primary)`; `@color.primary` gives the
      `reserved-sigil` diagnostic.
- [ ] All {{F03}} fixtures in `docs/spec/fixtures/values/` and
      `docs/spec/fixtures/references/` pass when typed with the vocabulary.
- [ ] Invalid values (`gap abc`, `variant huge`) produce `invalid-value`
      diagnostics with id and prop; nothing throws.
- [ ] For every typed value in the tests, `typeValue(formatValue(v))` equals
      `v` (round trip).
- [ ] The pull request contains the upstream issue draft and the URL above.
- [ ] `npm test`, `npm run lint`, `npm run format:check`,
      `npm run check:duplication` pass.
