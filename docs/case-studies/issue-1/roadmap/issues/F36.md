## Context

Components need icons (close, menu, chevrons, send, attach, zoom, dock and so
on). R26 says our own assets are public domain (CC0-1.0); R27 says third-party
icons are allowed, but each one links to its source and states its copyright,
licence and attribution
([requirements](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/requirements.md)).

What our projects do today:

- meta-sovereign `js/src/web/icons.js` uses Lucide shapes (ISC) drawn with
  `currentColor`
  ([research](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/meta-sovereign-chat.md)).
- formal-ai `js/app/toolbar-icons.jsx` switches between icon packs
  (fontawesome, material-symbols, bootstrap-icons, ionicons, remix-icon,
  tabler-icons, names) and hides overflow by `data-menu-priority`; emoji icons
  were unclear (https://github.com/link-assistant/formal-ai/issues/409)
  ([research](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/formal-ai.md)).

The library survey
([existing solutions](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/existing-solutions.md))
recommends Lucide (ISC; Feather-derived icons MIT) as the default third-party
set, Material Symbols (Apache-2.0, keep LICENSE and NOTICE) and Tabler (MIT);
Phosphor and Fluent System Icons (MIT) are also permissive. **Avoid** Remix
Icon (custom licence since January 2026) and SF Symbols (never bundle; native
Swift code may call `Image(systemName:)` only). The Iconify per-set metadata
(`license.spdx`, author, url) is the model for asset records, and REUSE 3.3
(`REUSE.toml`, `reuse lint`) is the compliance check.

The asset record format is already sketched in
[`samples/assets.lino`](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/samples/assets.lino):

```lino
(lucide-check: asset
  (kind icon)
  (source 'https://lucide.dev/icons/check')
  (license ISC)
  (copyright 'Lucide Contributors')
  (notice 'https://github.com/lucide-icons/lucide/blob/main/LICENSE'))
```

## Goal

The repository ships its own CC0 icon set under `assets/icons/`, an `icon`
element that renders any registered icon with `currentColor`, adapters for
Lucide, Tabler and Material Symbols that create asset records automatically,
and a build step that refuses any icon without a valid record.

## Scope

### In scope

- About 32 own icons needed by {{F26}}–{{F38}} (list in step 2), drawn from
  scratch on a 24×24 grid with a 2 px stroke, CC0-1.0.
- `icon-registry.js`: icon sets, lookup, fallbacks.
- `icon` element: decorative by default (`aria-hidden="true"`), labelled when
  `label` is set, optional mirroring in right-to-left layouts.
- Adapters `lucide`, `tabler`, `material-symbols` as optional peer
  dependencies, each emitting asset records.
- `scripts/build-icons.mjs`: reads `assets.lino`, checks every record, writes
  an ES module per set and a sprite.
- A generated `ATTRIBUTION.md`-style notice list in the package output.

### Out of scope

- Fonts (OFL, shipped separately) and images other than icons.
- Native Swift and Kotlin icon loading.
- The licence policy itself and REUSE CI ({{F02}}).

## Dependencies

- **Blocked by {{F02}}**: the asset record fields, the SPDX allow list and the
  CI check (`reuse lint`). If {{F02}} is not merged, read `assets.lino` with the
  `links-notation` parser and check the fields `kind`, `source`, `license`,
  `copyright` and `notice` locally; switch to the {{F02}} validator when it
  lands.
- **Blocked by {{F16}}**: the custom element base for `icon`.
- **Related:** {{F11}} (icon size tokens), {{F13}} (labels), {{F26}},
  {{F27}}, {{F30}}, {{F43}} (classic themes choose icon sets), {{F61}}
  (formal-ai drops `remix-icon` while migrating).

## Step-by-step plan

1. Create `assets/icons/own/` and draw the icons as plain SVG:
   `close, menu, more, chevron-up, chevron-down, chevron-left, chevron-right,
check, plus, minus, search, settings, reset, copy, paste, send, attach,
drag-handle, dock-left, dock-right, dock-bottom, float, zoom-in, zoom-out,
fit, play, pause, record, warning, error, info, link`. Never trace or copy a
   third-party icon.
2. Add one record per own icon to `assets.lino`, for example
   `(icon-close: asset (kind icon) (license CC0-1.0) (copyright none) (file 'assets/icons/own/close.svg'))`.
3. Write `packages/ui-components/src/icons/icon-registry.js`:
   ```js
   /**
    * @param {string} set e.g. 'own', 'lucide'
    * @param {{ resolve(name: string): Promise<IconData|undefined>, records(): AssetRecord[] }} source
    */
   export function registerIconSet(set, source) {}
   /** @returns {Promise<IconData>} falls back to the 'own' set, then to a placeholder */
   export function resolveIcon(ref) {}
   ```
   `IconData` is `{ viewBox, body, mirrorInRtl, record }`.
4. Write `icon.js` (element). In LiNo an icon is referenced without a colon,
   because `:` is not allowed in bare values:
   `(icon (set lucide) (name check))` or `(icon close)` for the own set.
5. Write adapters in `packages/ui-components/src/icons/adapters/`
   (`lucide.js`, `tabler.js`, `material-symbols.js`). Each imports the SVG data
   from the official npm package (check the current package names and
   versions), and returns records with source URL, SPDX licence, copyright and
   notice. Material Symbols must ship its LICENSE and NOTICE text.
6. Write `scripts/build-icons.mjs`: fails when a used icon has no record, when
   the licence is not in the allow list (MIT, ISC, BSD-2-Clause,
   BSD-3-Clause, Apache-2.0, CC0-1.0, CC-BY-4.0 with attribution), or when the
   source is Remix Icon or SF Symbols. Optimise SVG with SVGO (MIT, check the
   current version) and replace fixed colours with `currentColor`.
7. Generate `packages/ui-components/dist/icons/NOTICE.lino` listing all
   third-party records used.
8. Gallery `packages/ui-components/examples/icons.html` with all own icons and
   a set switcher.

- `assets/icons/own/*.svg`, `assets.lino`
- `packages/ui-components/src/icons/{icon-registry,icon}.js`

- `scripts/build-icons.mjs`

## Acceptance criteria

- [ ] Every file in `assets/icons/own/` has a CC0-1.0 record in `assets.lino`
      (test).
- [ ] `node scripts/build-icons.mjs` fails with a clear message for a fixture
      icon without a record and for a fixture record with
      `(license LicenseRef-RemixIcon)` (tests).
- [ ] Icons use `currentColor` and follow the text colour in light and dark
      themes (screenshot).
- [ ] An icon without `label` has `aria-hidden="true"`; with `label` it has
      `role="img"` and that name (Playwright plus axe).
- [ ] Switching the set to `lucide` changes the shapes; the generated notice
      file lists Lucide with ISC (test).
- [ ] `reuse lint` passes (when {{F02}} has added it).
- [ ] No dependency from the avoid list appears in any `package.json` (test).

## How to verify

```bash
node scripts/build-icons.mjs
node --test packages/ui-components/tests/icons/*.test.js
npx playwright test packages/ui-components/tests/e2e/icons.spec.js
npx reuse lint
npm run lint && npm run format:check && npm run check:duplication
```

Expected screenshots: the icon gallery with the own set, the Lucide set and the
Material Symbols set, in light and dark themes.

## Prior art and libraries

- Lucide (ISC), Tabler (MIT), Material Symbols (Apache-2.0): adapters.
- Phosphor, Fluent System Icons (MIT), Health Icons (CC0): possible later.
- Iconify metadata: model for records. REUSE 3.3 and SPDX: compliance.
- Remix Icon, SF Symbols: avoid.
