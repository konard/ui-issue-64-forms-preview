## Context

Edits made on our sites in dev/config mode (R11) must survive a reload and be
exportable (R9). The store from {{F08}} is in-memory only. The links platform
stores data as **doublets**: every link is a triple `(index, source, target)`
of unsigned integers. [`doublets-web`](https://github.com/linksplatform/doublets-web)
(Unlicense, npm 0.1.3 at planning time) exposes the Rust doublets engine to
the browser through WebAssembly:

```js
import { Link, LinksConstants, UnitedLinks } from 'doublets-web';
const links = new UnitedLinks(new LinksConstants());
const link = links.create();
links.update(link, link, link); // a "point": source = target = itself
```

Its README shows an in-memory API only (no IndexedDB layer). Prior art:

- formal-ai persists an append-only LiNo event log in IndexedDB (database
  `formal-ai-demo`, store `events`), exports `formal-ai-memory.lino`, puts
  import/reset/purge behind confirmations and reports doublets-web only if the
  global is present
  ([formal-ai.md](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/formal-ai.md)).
- meta-sovereign-chat mirrors its LiNo records into a doublets store
  (`js/src/storage/doublets-store.js`, `dual-store.js`,
  [meta-sovereign-chat.md](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/meta-sovereign-chat.md)).

## Goal

`@link-foundation/ui-store` gains `openPersistentStore()` that saves a store to
IndexedDB as a doublets table (`index`, `source`, `target`) plus names and an
operation log, restores it after reload, and can copy the same table into a
`doublets-web` `UnitedLinks` instance.

## Scope

### In scope

- Encoding a `UiDocument` into doublets and back (`src/doublets/encode.js`).
- IndexedDB schema, write-through on every committed transaction, load,
  compaction, export/import of a `.lino` bundle, `destroy()`.
- Optional adapter to `doublets-web` (`src/doublets/web-adapter.js`) loaded by
  dynamic `import()` only when requested.
- Multi-tab notification through `BroadcastChannel`.

### Out of scope

- Server sync, conflict resolution between tabs (last writer wins, documented).
- Making `doublets-web` itself persist (that belongs upstream).

## Dependencies

- {{F08}} (blocker): `createStore`, `subscribe`, `log()`, `logToLino`,
  `logFromLino`, `toLino`. Consumed: committed transactions and the operation
  log. Before it merges, stub a store with `subscribe` and `toLino` only.
- Related: {{F10}} (persists its user layer with this), {{F46}}, {{F45}}.

## Step-by-step plan

1. Doublets encoding, `src/doublets/encode.js`:
   - every distinct reference string (`ok`, `button`, `label`, `OK`) becomes a
     point link `(i, i, i)`; a `names` table maps string → index;
   - an n-ary link `(a b c)` becomes left-folded pairs `((a b) c)`, i.e.
     `p1 = (p1, a, b)`, `p2 = (p2, p1, c)`; identical pairs are reused
     (deduplicated), as in a doublets store;
   - an element `ok: button ...` is encoded as the pair (name point, body).
   ```js
   /** @returns {{ links: Array<{index:number, source:number, target:number}>, names: Map<string, number>, roots: number[] }} */
   export function encodeDocument(doc) {}
   /** @returns {UiDocument} */
   export function decodeDocument({ links, names, roots }) {}
   ```
   Indexes start at 1 (0 is reserved, as in doublets).
2. IndexedDB schema (`src/idb/schema.js`), database `link-ui-<name>`,
   version 1:

   | Object store | keyPath      | Indexes                               | Content                                |
   | ------------ | ------------ | ------------------------------------- | -------------------------------------- |
   | `links`      | `index`      | `source`, `target`, `[source+target]` | doublets triples                       |
   | `names`      | `name`       | `index` (unique)                      | reference string → point               |
   | `log`        | `seq` (auto) | `tx`                                  | `{ seq, tx, lino }` entries            |
   | `meta`       | `key`        | —                                     | `schemaVersion`, `roots`, `snapshotTx` |

   Use the raw IndexedDB API with small promise helpers (`src/idb/request.js`);
   no wrapper library is required.

3. `src/persistent.js`:
   ```js
   /**
    * @param {{ name: string, indexedDB?: IDBFactory, initialText?: string, channel?: boolean }} options
    * @returns {Promise<{ store: Store, persistence: Persistence }>}
    */
   export async function openPersistentStore(options) {}
   // persistence.flush(): Promise<void>; persistence.compact(): Promise<void>
   // persistence.exportBundle(): Promise<string>; persistence.importBundle(text): Promise<void>
   // persistence.close(); persistence.destroy(): Promise<void>
   ```
   Load: read `meta.roots`, `links`, `names` → `decodeDocument` → replay `log`
   entries with `tx > snapshotTx`. Without data, use `initialText`.
4. Write-through: subscribe to the store; for each committed transaction
   append one `log` row (the LiNo of the transaction from {{F08}}) in a single
   IndexedDB `readwrite` transaction. `flush()` resolves when all queued
   writes finish.
5. `compact()`: rewrite `links`/`names` from the current document, set
   `snapshotTx`, delete older `log` rows.
6. Bundle format (`exportBundle`), one LiNo document:
   ```lino
   (ui_store_bundle (schema 1) (name demo) (snapshot_tx 12))
   (document ...current document LiNo...)
   (tx 13 (origin devmode) (setProp ok label 'Cancel'))
   ```
   `importBundle` validates it with `ui-core` (limits on size and depth) and
   replaces the content in one transaction. UI code must ask for confirmation
   before import/destroy (as in formal-ai); this package only exposes the calls.
7. `src/doublets/web-adapter.js`: `copyToDoubletsWeb(encoded, unitedLinks)`
   creates links in a `UnitedLinks` instance in index order and returns the
   index map. Check the current `doublets-web` API (README on branch `master`)
   before writing it; `doublets-web` is an optional peer dependency.
8. `BroadcastChannel('link-ui-<name>')`: post `{ tx }` after each write; other
   tabs call `persistence.reload()`.
9. Tests with [`fake-indexeddb`](https://www.npmjs.com/package/fake-indexeddb)
   (dev dependency, Apache-2.0, 6.2.7 at planning time) passed through the
   `indexedDB` option.

## Acceptance criteria

- [ ] `doublets-encode.test.js`: for every sample document,
      `decodeDocument(encodeDocument(doc))` deep-equals `doc`; every triple has
      integer `index`, `source`, `target` ≥ 1; no two triples share
      `(source, target)` except points.
- [ ] `persistent.test.js`: open a store, run 50 seeded edits, close, reopen
      with the same `name` → `toLino()` is identical; undo still works for edits
      made after reopening.
- [ ] `compact.test.js`: after `compact()`, the `log` store is empty and the
      reloaded document is identical.
- [ ] `bundle.test.js`: `importBundle(exportBundle())` into a fresh database
      gives the same document; a bundle deeper than `maxDepth` or larger than
      the size limit is rejected with an error and no data change.
- [ ] `web-adapter.test.js` runs when `doublets-web` can be loaded in Node and
      is skipped (with a reason) otherwise; it checks `links.count()` equals the
      number of triples.
- [ ] `destroy()` deletes the database: opening `link-ui-<name>` again
      triggers `upgradeneeded` with `oldVersion === 0`.
- [ ] `npm test`, `npm run lint`, `npm run format:check`,
      `npm run check:duplication` pass.
