## Context

Requirement R15 asks us to follow the Google, Microsoft and Apple guidelines
so that moving off Material UI (MUI) and similar frameworks is easy. Many of
our projects, and many outside ones, use MUI. The Deep 2025 rewrite is one of
them: it runs MUI 6 in dark mode
([deepcase.md](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/deepcase.md)).

The research recommends this route
([existing-solutions.md](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/existing-solutions.md)):

1. Implement Material 3 as a theme package. M3 tokens are `md.ref.*`
   (reference) and `md.sys.*` (system), and palettes are generated from a
   seed colour with material-color-utilities (Apache-2.0).
2. Add a converter from an MUI theme object to LiNo tokens.
3. Add a mapping table from MUI component and prop names to ours.

Material Web (MWC) is in maintenance mode
(https://github.com/material-components/material-web/discussions/5642), so
**do not depend on it**. MUI Core is MIT, but MUI X Pro and Premium are
commercial, so never import them.

## Goal

Ship `material3`, a theme package with light, dark and high-contrast schemes,
built on the {{F39}} engine and following the Material 3 digest from {{F04}}.
Alongside it, ship `muiThemeToLino()` and a machine-readable MUI-to-UI mapping
table. The JSX importer ({{F51}}) and the migration guide ({{F57}}) both
consume that table.

## Scope

### In scope

- `packages/ui-themes/themes/material3/`:
  - colour roles (`primary`, `on-primary`, `primary-container`, `secondary`,
    `tertiary`, `error`, `surface`, `surface-container-*`, `outline` and so
    on) for light, dark and high contrast;
  - the type scale (display, headline, title, body and label, each in large,
    medium and small);
  - the shape scale, elevation levels, the motion easing and duration tokens,
    and the state-layer opacities.
- Style rules and component templates for the {{F26}} controls: filled,
  tonal, outlined, text and elevated buttons, text field (filled and
  outlined), checkbox, radio, switch and slider.
- `materialThemeFromSeed(seed, options)`, which builds a full LiNo theme from
  one seed colour with `@material/material-color-utilities`.
- `muiThemeToLino(themeOptions)`, which converts a plain MUI `createTheme`
  options object into a LiNo theme that extends `material3`. It must not
  depend on MUI.
- `mui-mapping.lino`, which maps MUI component names, props and prop values
  to our kinds and props, and marks each row's status.

### Out of scope

- Parsing JSX or `sx` props, which belongs to {{F51}}. Writing the migration
  guide prose, which belongs to {{F57}}.
- Material 3 Expressive (2025) variants. A follow-up issue can add them as a
  second package.
- Bundling Roboto or Material Symbols. Roboto is only named in the
  `font-family` stack, and icons come from {{F36}}.
- MUI X (data grid, date pickers). Only rows for components we own are mapped.

## Dependencies

- {{F39}} (blocker). Supplies the theme package format, the modes, the
  contrast check, the templates and `compileThemeCss`.
- {{F04}} (blocker). Supplies the Material 3 section of the design guidelines
  digest: token names, roles, values and component rules, with source links.
  To start before {{F04}} merges, take the values from https://m3.material.io,
  record each source URL in the theme file comments, and reconcile once
  {{F04}} lands.
- Related: {{F26}}, {{F27}}, {{F29}} (component names in the mapping table),
  {{F41}}, {{F42}}, {{F51}}, {{F54}}, {{F55}}, {{F57}}.

## Step-by-step plan

1. Add `@material/material-color-utilities` as a dependency of
   `packages/ui-themes` (Apache-2.0; check the current version). Record its
   licence in the package README.
2. Write `scripts/generate-material3.mjs`. It calls
   `materialThemeFromSeed('#6750A4')`, the M3 baseline seed, and writes
   `themes/material3/colors.lino`. Generated values are committed, so the
   build does not need the generator. The generated file must look like this:
   ```lino
   (material3-colors: theme
     (token color.primary '#6750A4')
     (token color.on-primary '#FFFFFF')
     (pair color.on-primary color.primary)
     (mode dark
       (token color.primary '#D0BCFF')
       (token color.on-primary '#381E72')))
   ```
   Do not copy these numbers. Take the real values from the generator output.
3. In `src/material3/seed.js`, implement:
   ```js
   /** @param {string} seed hex colour
    * @param {{ id?: string, contrast?: number, variant?: 'tonal-spot' | 'vibrant' | 'neutral' }} [options]
    * @returns {string} LiNo theme text with light, dark and high-contrast modes */
   export function materialThemeFromSeed(seed, options) {}
   ```
4. Write `themes/material3/theme.lino`. It does `(extends base)` and pulls in
   `colors.lino`, `type.lino`, `shape.lino`, `elevation.lino` and
   `motion.lino`.
   - Names map from M3 to ours, for example `md.sys.color.primary` becomes
     `color.primary` and `md.sys.shape.corner.medium` becomes
     `shape.corner.medium`.
   - Each file records the original M3 token name next to our name as
     `(m3 md.sys.color.primary)`, so a reverse export is possible.
   - Take the type-scale, shape, elevation and motion values from the {{F04}}
     digest, and check every value against m3.material.io.
5. Write `themes/material3/styles.lino` and `templates.lino` for the
   in-scope controls. Use the state layers with `(state hover ...)`,
   `(state focus ...)` and `(state pressed ...)` from {{F12}}. The focus ring
   must remain visible in high-contrast and forced-colours modes.
6. In `src/material3/mui.js`, implement:

   ```js
   /** @param {object} themeOptions plain object passed to MUI createTheme()
    * @param {{ id?: string }} [options]
    * @returns {{ lino: string, unmapped: string[] }} */
   export function muiThemeToLino(themeOptions, options) {}
   ```

   Map these fields, and list every other path in `unmapped`:
   - `palette.mode`;
   - `palette.{primary,secondary,error,warning,info,success}.{main,contrastText}`;
   - `palette.background.{default,paper}` and `palette.text.{primary,secondary}`;
   - `shape.borderRadius`, `spacing` (when it is a number), `typography.fontFamily`;
   - `breakpoints.values` and `transitions.duration`.

   An example output:

   ```lino
   (mui-import: theme
     (extends material3)
     (token color.primary '#1976D2')
     (token color.on-primary '#FFFFFF')
     (token shape.corner.small 4px)
     (token space.unit 8px))
   ```

7. Write `themes/material3/mui-mapping.lino`, with one link per row:

   ```lino
   (map Button (kind button)
     (prop variant contained (variant filled))
     (prop variant outlined (variant outlined))
     (prop variant text (variant text))
     (status mapped))
   (map TextField (kind text-field) (status partial))
   ```

   - Cover at least these MUI components: Button, IconButton, TextField,
     Checkbox, Radio, RadioGroup, Switch, Slider, Select, Dialog, Menu,
     Tooltip, Snackbar, Drawer, AppBar, Tabs, Card, List, Table, Chip, Avatar,
     Badge, Box, Stack, Grid, Typography and CircularProgress.
   - Use the kind names actually merged in {{F26}}–{{F29}}, and mark a row
     `(status none)` when we have no equivalent yet.
   - Export `getMuiMapping()`, which returns the parsed table as plain
     objects.

8. Write `docs/themes/material3.md`. It holds a generated Markdown version of
   the mapping table, produced by `scripts/mapping-to-md.mjs`; do not edit it
   by hand.
9. In `examples/themes/material3.html`, build a gallery page that shows all
   in-scope controls in light, dark and high contrast. Add Playwright
   screenshots, tests and a changeset.

## Acceptance criteria

- [ ] `material3-theme.test.js`: the package loads with zero error
      diagnostics, and every `pair` passes 4.5:1 in light, dark and high
      contrast.
- [ ] Running `generate-material3.mjs` twice produces byte-identical
      `colors.lino` (determinism test).
- [ ] `material3-seed.test.js`: for the baseline seed `'#6750A4'`, `primary`
      equals the material-color-utilities output for the same seed.
- [ ] `mui-theme.test.js`: each fixture converts to LiNo that parses with
      `links-notation` and loads in {{F39}}. `unmapped` lists unknown paths.
      `palette.primary.main` becomes `color.primary`.
- [ ] `mui-mapping.test.js`: every listed MUI component has a row, every
      `kind` in a `mapped` or `partial` row is a registered kind, and the
      generated `docs/themes/material3.md` is up to date. The test regenerates
      it and compares.
- [ ] No dependency on `@material/web`, `@mui/*` or any Roboto or Material
      Symbols font package (`npm ls` checks are in the test).
- [ ] Playwright screenshots of the gallery in light, dark and high contrast
      are attached to the pull request, and axe reports no violations.
- [ ] `npm run lint`, `npm run format:check`, `npm run check:duplication` and
      `npm test` pass.
