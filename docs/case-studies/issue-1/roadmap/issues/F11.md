## Context

Themes ({{F39}}–{{F43}}) for Material 3, Fluent, Apple HIG and classic UIs are
mostly sets of design tokens (R14, R15). The research
([existing-solutions.md](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/existing-solutions.md))
decided: **LiNo is the source, DTCG 2025.10 is the exchange format**, with a
three-layer token model (reference → semantic → component). The W3C Design
Tokens Community Group Format Module 2025.10 (published 2025-10-28) is JSON
with `$value`, `$type`, `$description`, aliases `{group.token}` and composite
types, with companion Color and Resolver modules. Style Dictionary (v4/v5,
Apache-2.0) already transforms DTCG to CSS, Swift and Kotlin.

The token sample
[samples/tokens.lino](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/samples/tokens.lino):

```lino
(material3: theme
  (extends base)
  (token color.primary '#6750A4')
  (token color.on-primary '#FFFFFF')
  (token space.medium 16px)
  (token shape.corner.medium 12px)
  (token motion.duration.short 150ms))
```

meta-sovereign-chat already uses about 60 hand-written CSS custom properties
(`--bg`, `--accent`, `--bubble-radius`, `--control-h`, ...)
([meta-sovereign-chat.md](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/meta-sovereign-chat.md))
that should become tokens.

## Goal

`packages/ui-tokens` (`@link-foundation/ui-tokens`) reads token sets written in
LiNo (with inheritance, aliases and modes), validates them, and exports CSS
custom properties, DTCG 2025.10 JSON, Swift and Kotlin constants; it also
imports DTCG JSON back to LiNo.

## Scope

### In scope

- Token grammar: `(token PATH VALUE (description '...') (type T))`, aliases as
  values (`(token color.action (token color.primary))`, the canonical
  `token-ref` form of {{F07}}), `(extends OTHER)`, modes
  `(mode dark (token ...))`.
- Types: `color`, `dimension`, `duration`, `number`, `fontFamily`,
  `fontWeight`, `cubicBezier`; composites `shadow` and `typography`.
- `resolveTokens` (inheritance, modes, aliases, cycle detection).
- Exporters: CSS, DTCG JSON, Swift, Kotlin; importer: DTCG JSON → LiNo.
- Optional Style Dictionary backend via a subpath export.
- CLI `link-ui-tokens`.

### Out of scope

- Real Material/Fluent/HIG token sets ({{F40}}–{{F42}}); theme switching UI
  ({{F39}}); style rules ({{F12}}).
- Figma/Penpot sync (later interop issue {{F53}}).

## Dependencies

- {{F07}} (blocker): typed values — dimension, duration, colour (hex and
  `oklch`), `token-ref`, `toCss`, `toHex`. Before it merges, keep a minimal local
  parser for `px`, `ms` and quoted hex and replace it at the end.
- Related: {{F06}} (`parse`), {{F10}} (`theme` layer), {{F12}}, {{F16}}
  (injects the CSS), {{F22}}/{{F24}} (use Swift/Kotlin output), {{F39}}.

## Step-by-step plan

1. Create `packages/ui-tokens/package.json`
   (`"name": "@link-foundation/ui-tokens"`, `"bin": { "link-ui-tokens": "./bin/cli.js" }`,
   exports `.` and `./style-dictionary`), dependency `@link-foundation/ui-core`.
2. `src/model.js`:
   ```js
   /** @typedef {{ path: string, type: string, value: TypedValue, description?: string, mode?: string }} Token */
   /** @typedef {{ id: string, extends: string[], tokens: Token[], modes: Record<string, Token[]> }} TokenSet */
   /** @returns {{ sets: Map<string, TokenSet>, diagnostics: Diagnostic[] }} */
   export function readTokens(text) {}
   ```
3. `src/resolve.js`: `resolveTokens(sets, setId, { mode }) → Map<path, ResolvedToken>`
   — apply `extends` (later wins), then mode overrides, then aliases; report
   `unknown-alias`, `alias-cycle`, `type-mismatch` diagnostics.
4. `src/export/css.js`: `toCss(resolved, { selector = ':root', prefix = '', modeSelector })`.
   Path `color.on-primary` → `--color-on-primary`. Aliases stay as
   `var(--color-primary)` so runtime changes cascade. Output for the sample:
   ```css
   :root {
     --color-primary: #6750a4;
     --color-on-primary: #ffffff;
     --space-medium: 16px;
     --shape-corner-medium: 12px;
     --motion-duration-short: 150ms;
   }
   ```
   Modes: `[data-mode="dark"] { ... }` by default; option
   `modeMedia: { dark: '(prefers-color-scheme: dark)' }`.
5. `src/export/dtcg.js`: `toDtcg(resolved, { keepAliases: true })` → nested
   object, e.g. `{ "space": { "medium": { "$type": "dimension", "$value": { "value": 16, "unit": "px" } } } }`;
   aliases as `"{color.primary}"`. Use the colour value shape of the 2025.10
   Color module (object with `colorSpace`, `components`, `alpha`, optional
   `hex`) — confirm the exact field names in the spec before coding and quote
   the section in a comment.
6. `src/import/dtcg.js`: `fromDtcg(json, { id }) → string` (LiNo text).
7. `src/export/swift.js`: `toSwift(resolved, { name: 'Tokens' })` →
   `public enum Tokens { public static let colorPrimary = Color(red: 0.404, green: 0.314, blue: 0.643, opacity: 1) ... }`
   (`import SwiftUI`; dimensions as `CGFloat`, durations as `TimeInterval`
   seconds: `0.15`).
8. `src/export/kotlin.js`: `toKotlin(resolved, { packageName, name: 'Tokens' })`
   → `object Tokens { val ColorPrimary = Color(0xFF6750A4); val SpaceMedium = 16.dp; const val MotionDurationShortMs = 150 }`
   with the Compose imports.
9. `src/style-dictionary.js` (subpath `./style-dictionary`): `buildWithStyleDictionary(resolved, config)`
   writes DTCG JSON to a temp dir and runs Style Dictionary (optional peer
   dependency `style-dictionary`, Apache-2.0, 5.7.1 at planning time).
10. `bin/cli.js` using `lino-arguments` (already a root dev dependency; check
    it fits a CLI) or `node:util` `parseArgs`:
    `link-ui-tokens build tokens.lino --set material3 --css out.css --dtcg out.json --swift Tokens.swift --kotlin Tokens.kt`.
11. Golden files in `tests/golden/` for every exporter; README with the grammar.

## Acceptance criteria

- [ ] `read.test.js`: `samples/tokens.lino` gives 5 tokens with types
      `color`, `color`, `dimension`, `dimension`, `duration`.
- [ ] `resolve.test.js`: `extends` and `mode dark` override correctly; an alias
      cycle `a → b → a` gives `alias-cycle` and no exception.
- [ ] Each exporter output for `samples/tokens.lino` equals its golden file.
- [ ] `dtcg.test.js`: `readTokens(fromDtcg(toDtcg(r)))` resolves to the same
      tokens (lossless round trip) for the sample and a fixture with aliases,
      modes, a `shadow` and a `typography` composite.
- [ ] The DTCG golden file validates with Terrazzo or Style Dictionary DTCG
      parsing (run once, note the tool and version in the pull request).
- [ ] `cli.test.js`: the command in step 10 writes the four files.
- [ ] Style Dictionary is not in `dependencies` (only an optional peer);
      `npm ls style-dictionary` in `packages/ui-tokens` is empty by default.
- [ ] `npm test`, `npm run lint`, `npm run format:check`,
      `npm run check:duplication` pass.
