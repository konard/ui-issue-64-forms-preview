## Context

R16 asks for a visualisation of a single link first, then of a links network
({{F34}}) and of any Links Notation text ({{F35}}). The reference drawings are in
https://github.com/konard/links-visuals (Unlicense, so the code can be ported)
([research](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/konard-github-io-and-links-visuals.md)):

- `js/markers.mjs`: cross and arrow markers, `viewBox 0 0 100 100`,
  `markerUnits="strokeWidth"`, golden-ratio proportions, colour hard-coded to
  black.
- `js/path.mjs` (Catmull-Rom to cubic Bézier), `js/geometry.mjs`,
  `js/control-points.mjs`, `js/ik-pure.mjs` (`IK_SEG_COUNT = 4`),
  `js/draw-link.mjs` (`applyCenterAnchors`, centre by arc length).
- `js/zoom-pan.mjs` (zoom factor `0.999 ** delta`, scale 0.1–20,
  document-level listeners, `?debug=zoom`), `js/grid.mjs` (infinite pattern).
- Pages `blueprint.html` (nine points: start green, end red, centre black,
  others blue, dashed `4 2`), `grid.html` (1–64 links), `draw.html` (pointer
  drawing with snapping, saved in localStorage).
- Problems to fix while porting: global state in `js/state.mjs`, a second
  renderer in `js/canvas-render.mjs` that duplicates the SVG one, an animation
  loop in `js/animation.mjs` that never stops, and D3 v7 loaded from esm.sh
  without a pinned version.

The konard.github.io network editor draws the same idea as glyphs (a bar at the
source, an arrow at the target, references touching the middle of a link, `0`
as a free end, a self-reference as a loop, `(1: 1 1)` drawn as ∞). That
repository has **no licence**, so we may learn from it but must not copy its
code (same research file).

## Goal

`@link-foundation/ui-components` provides a `link-view` element and pure
geometry functions that draw one link (source, target, centre anchor, markers,
optional blueprint points) with one shared marker definition for SVG and
Canvas, instance-scoped zoom and pan, and no animation work when nothing moves.

## Scope

### In scope

- Pure geometry: control points, Catmull-Rom to cubic conversion, arc-length
  centre, self-loop path.
- One `markers.js` with marker shapes (`bar`, `arrow`, `cross`, `dot`, `none`)
  used by both the SVG and the Canvas back ends; colours from tokens.
- `renderLinkSvg` (string, deterministic) and `drawLinkCanvas(ctx, …)`.
- `createZoomPan(element, options)` without global state, with `destroy()`.
- `createAnimator()` that runs `requestAnimationFrame` only while something is
  animating and respects `prefers-reduced-motion`.
- Blueprint mode (the nine points) and the infinite background grid.

### Out of scope

- Many links, layouts and workers ({{F34}}); LiNo-to-network conversion
  ({{F35}}).
- The draw page and inverse kinematics editing (follow-up issue; keep
  `ik-pure` only if the geometry needs it).
- Migrating the links-visuals site ({{F59}}).

## Dependencies

- **Blocked by {{F16}}**: the custom element base used by `link-view`. All
  geometry and the SVG string renderer are pure and can be written first.
- **Related:** {{F11}} (tokens `color.link.source`, `color.link.target`,
  `color.link.line`), {{F34}}, {{F35}}, {{F44}} (animation engine), {{F59}}
  (links-visuals migrates to this package).

## Step-by-step plan

1. Create `packages/ui-components/src/links-view/` and export it.
2. Port `path.mjs`, `geometry.mjs` and `control-points.mjs` into
   `geometry.js` with tests that use fixed inputs:
   ```js
   /**
    * @param {{ source: Point, target: Point, bend?: number, selfLoop?: boolean }} input
    * @returns {{ path: CubicSegment[], center: Point, length: number }}
    */
   export function linkGeometry(input) {}
   /** @returns {Point} point at arc-length fraction t (0..1) */
   export function pointAtLength(path, t) {}
   ```
3. Write `markers.js`: each marker is data
   `{ id, viewBox: '0 0 100 100', path, refX, refY }`; `svgMarkerDefs(markers,
tokens)` returns `<marker>` elements and `drawMarker(ctx, marker, at,
angle, scale)` draws the same path with `Path2D`. Colours come from tokens,
   not from the code.
4. Write `render-svg.js`: `renderLinkSvg(geometry, style) → string`, and
   `render-canvas.js`: `drawLinkCanvas(ctx, geometry, style)`. Both read
   `markers.js`; a test checks that both use the same marker ids.
5. Write `zoom-pan.js`:
   `createZoomPan(element, { min = 0.1, max = 20, onChange }) → { get(), set(view), destroy() }`.
   Listeners are attached to `element` (pointer capture while dragging), not to
   `document`, and `destroy()` removes them (test with a fake element).
6. Write `animator.js`: `createAnimator({ now, raf })` with `start(id, fn)`
   and `stop(id)`; the frame loop stops when no animation is active. Inject
   `now` and `raf` for tests.
7. Write the `link-view` element: draws one link from LiNo, optional
   `blueprint` points and `grid`, keyboard zoom (`+`, `-`, `0` to reset) and an
   accessible name such as "Link 1 from 1 to 2".
8. Pin D3 modules if used (`d3-zoom` is optional; plain pointer code is
   enough). Never load scripts from a CDN at run time.
9. Gallery page `packages/ui-components/examples/link-view.html` with: a
   simple link, a self-loop, a link with a free end, and the blueprint mode.

Input example (working names; the dialect is fixed in {{F03}}):

```lino
(simple: link-view
  (link (id 1) (source 1) (target 2))
  (markers (source bar) (target arrow))
  (blueprint true)
  (grid true))
```

## Acceptance criteria

- [ ] `geometry.test.js` checks the centre of a straight link and of a curved
      link against fixed numbers (tolerance 1e-6).
- [ ] SVG and Canvas renderers import marker shapes only from `markers.js`
      (test scans imports) and produce matching pixels within 2 % in a
      Playwright pixel comparison.
- [ ] No module in `src/links-view/` has module-level mutable state (lint rule
      or test).
- [ ] With nothing moving, no `requestAnimationFrame` callback runs for 1
      second (test with the injected `raf`).
- [ ] Two `link-view` elements on one page zoom independently (Playwright).
- [ ] `renderLinkSvg` gives identical output on two runs (snapshot).
- [ ] No network request goes to esm.sh or any CDN (Playwright).

## How to verify

```bash
node --test packages/ui-components/tests/links-view/*.test.js
npx playwright test packages/ui-components/tests/e2e/link-view.spec.js
npm run lint && npm run format:check && npm run check:duplication
```

Expected screenshots: the four gallery cases in light and dark themes; the
blueprint case shows the start point green, the end point red, the centre
black (or the token colour in dark mode) and the other points blue with a
dashed `4 2` guide.
