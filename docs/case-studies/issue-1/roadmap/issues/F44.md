## Context

R6 says any UI framework is "just" a LiNo document, and that includes its
animations. R4 asks for recordable animations, which {{F45}} builds on this
issue. `@link-foundation/ui-animation` is the package that holds the
keyframe, spring and timeline model and a player built on the Web Animations
API (WAAPI)
([`docs/ARCHITECTURE.md`](https://github.com/link-foundation/ui/blob/main/docs/ARCHITECTURE.md)).
The verified sample
https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/samples/animation.lino
contains this link:

```lino
(press-feedback: animation
  (target ok)
  (duration (token motion.duration.short))
  (easing standard)
  (track scale (key 0 1) (key 0.5 0.96) (key 1 1)))
```

Lessons from our repositories
([immortality-and-anime-avatar.md](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/immortality-and-anime-avatar.md)):

- **Pure functions of time.** In immortality, `decipherFrame(text, t, seed)`
  is a pure function of time. In anime-avatar,
  `ACS_gestureDelta(name, t, mood, easing)` is stateless. Animations built
  this way are deterministic, so they can be scrubbed, recorded and tested.
- **Additive layering.** anime-avatar sums deltas from every motion source
  and applies bell or sustained envelopes, so nothing snaps
  (https://github.com/konard/anime-avatar/tree/main/docs/case-studies/issue-28).
- **Regressions to guard against.** `animation-fill-mode: both` left
  `clip-path` and transforms on panels after the animation ended, and a
  `steps(1)` white flash was a photosensitivity hazard
  (https://github.com/konard/immortality/tree/main/docs/case-studies/issue-7).
- **Reduced motion.** `motionAllowed()` combines the user toggle with
  `prefers-reduced-motion`.

On libraries: WAAPI is ADOPT. Motion is MIT and optional. **GSAP is
forbidden**, because its licence bans competing no-code animation tools
([existing-solutions.md](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/existing-solutions.md)).

## Goal

Create `packages/ui-animation/` with four parts:

1. a LiNo animation model: tracks of keyframes, easings, springs, timelines,
   stagger, additive composition, state triggers and named procedural
   effects;
2. a pure evaluator `sample(animation, t)`;
3. a compiler to WAAPI keyframes and options;
4. a player driven by an injectable clock.

Reduced motion and flash safety are enforced by the model itself.

## Scope

### In scope

- The `animation` link: `target`, `duration`, `delay`, `iterations`,
  `direction`, `fill` (default `none`), `composite` and `easing` (named
  tokens, `(cubic-bezier a b c d)`, `(steps n)`, `(spring ...)`), plus
  `(track <property> (key <offset> <value> [easing]))` and
  `(reduced-motion ...)` overrides.
- The `timeline` link, with `(at <time> (play <id> ...))`, `(sequence ...)`,
  `(parallel ...)` and `(stagger <step> ...)`.
- State triggers. `(on pressed (play press-feedback))` binds to the
  {{F12}} states `hover`, `focus`, `pressed` and `disabled`. This follows
  the XAML VisualState pattern.
- Value interpolation for numbers, lengths with units, colours (OKLCH, via
  {{F07}}), opacity, `translate`, `scale` and `rotate`.
- Effects registry. `registerEffect(name, fn)` takes pure
  `(input, t, seed) => output` functions. The first one is `decipher`,
  ported from immortality `textEffects.ts`, which is Unlicense.
- Additive layers with `envelope bell` and `envelope sustain`.
- The player: WAAPI for CSS-animatable properties, and a clock-driven frame
  loop for effects and non-CSS properties.
- The safety validator, which covers the fill-mode rule and photosensitive
  flashes.

### Out of scope

- The recorder and replay ({{F45}}), the timeline editor UI ({{F49}}) and
  Lottie import ({{F53}}).
- Native animation output (SwiftUI, Compose and React Native `Animated`),
  which belongs to {{F21}}, {{F23}} and {{F20}}. Keep the model
  platform-neutral so those renderers can map it.
- A Motion (MIT) adapter. It may come later as an optional peer dependency.
  GSAP is never used.
- View Transitions and scroll-driven timelines, which come in a follow-up.

## Dependencies

- {{F12}} (blocker). Supplies style states (`hover`, `pressed` and so on) and
  token resolution, so `(token motion.duration.short)` and `(easing standard)`
  resolve from the active theme.
- {{F16}} (blocker). Supplies `handle.nodeFor(id)`, which resolves `(target ok)`
  to a DOM node, and the store change events that fire state triggers.
- Indirect: {{F07}}, which provides typed durations, lengths and colours.
- Related: {{F25}} (behaviour machines can `play` animations), {{F39}}
  (`data-motion` and the comfort keys), {{F45}}, {{F49}}, {{F53}}, {{F63}},
  {{F64}}.
- The model, evaluator and validator (steps 1–5) need no DOM. Start there;
  steps 6–7 need {{F16}}, and a test can stub `nodeFor` until it merges.

## Step-by-step plan

1. Create `packages/ui-animation/package.json` (`@link-foundation/ui-animation`,
   ESM) with no runtime dependencies besides the workspace packages and
   `links-notation`. Add a README.
2. `src/model.js` exposes
   `/** @returns {{ animations: Map<string, Animation>, timelines: Map<string, Timeline>, diagnostics: Diagnostic[] }} */ loadAnimations(linoText)`.
   It accepts this input (the final syntax is fixed by {{F03}}):
   ```lino
   (panel-enter: animation
     (duration 300ms)
     (easing (cubic-bezier 0.2 0 0 1))
     (fill backwards)
     (track opacity (key 0 0) (key 1 1))
     (track translate (key 0 '0 8px') (key 1 '0 0'))
     (reduced-motion (duration 0ms)))
   (bounce: animation
     (duration 600ms)
     (easing (spring (stiffness 300) (damping 20) (mass 1)))
     (track scale (key 0 0.9) (key 1 1)))
   (title-reveal: animation (target title) (duration 900ms) (effect decipher (seed 42)))
   (intro: timeline
     (at 0ms (play panel-enter (target sidebar)))
     (at 120ms (stagger 50ms (play bounce) (targets item-1 item-2 item-3))))
   ```
   Keyframe offsets must be in the range 0–1 and sorted. Each violation is a
   diagnostic.
3. `src/easing.js` provides `cubicBezier(a, b, c, d)` and `steps(n)`, which
   return `(x) => y`. `spring({ stiffness, damping, mass })` returns
   `{ at(t), settleTime }`, a closed-form damped oscillator.
   `toCssLinear(fn, samples = 40)` returns a CSS `linear()` string, so
   springs can run on WAAPI.
4. `src/sample.js` provides
   `/** Pure. @returns {Record<string, unknown>} */ sample(animation, tMs, { seed })`,
   which handles keyframe interpolation, delay, iterations, direction and
   effects. `sampleLayers(layers, tMs)` sums `composite add` layers with
   their envelopes.
   - Effects are pure functions; `decipher` returns the same string for the
     same `(text, t, seed)`.
   - Randomness only comes from `seededRandom(seed)`, never from
     `Math.random`.
5. `src/validate.js` provides `validateAnimation(animation) -> Diagnostic[]`,
   with these rules:
   - **fill.** `fill both` or `fill forwards` on `clip-path`, `transform`,
     `translate`, `scale` or `rotate` is an error unless the animation
     declares `(persist true)`. This is the immortality issue-7 regression.
   - **flash.** Sample at 60 Hz. Over any one-second window, more than 3
     luminance changes of at least 10 percent of relative luminance, in an
     `opacity`, `background-color` or `color` track, is an error. This
     follows WCAG 2.3.1, and it catches the `steps(1)` white-flash
     regression.
   - **reduced-motion.** Any movement track (`translate`, `scale` or
     `rotate`) longer than 0ms with no `(reduced-motion ...)` block gets a
     warning, because the default reduced behaviour is a cross-fade.
6. `src/compile-waapi.js` provides
   `toWaapi(animation, { resolveToken }) -> { keyframes, options }`. For the
   sample `press-feedback`, it must produce:
   ```js
   ({
     keyframes: [
       { offset: 0, scale: '1' },
       { offset: 0.5, scale: '0.96' },
       { offset: 1, scale: '1' },
     ],
     options: {
       duration: 150,
       easing: '<resolved standard easing>',
       fill: 'none',
       composite: 'replace',
     },
   });
   ```
   The duration of 150 comes from the sample token `motion.duration.short`
   in https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/samples/tokens.lino.
7. `src/player.js` provides:

   ```js
   /** @param {{ nodeFor(id: string): Element | null }} handle
    * @param {{ clock?: { now(): number, requestFrame(cb: () => void): number },
    *   motion?: () => 'full' | 'reduced', animate?: Function }} [options] */
   export function createPlayer(handle, options) {}
   // player.play(id, { target }) -> { finished: Promise<void>, pause(), seek(ms), cancel() }
   // player.bindTriggers(store) -> unsubscribe
   ```

   - When `motion()` returns `'reduced'`, apply the `(reduced-motion ...)`
     block. Without one, use opacity-only tracks with duration 0.
   - `motion` defaults to reading `data-motion` on the target's theme
     boundary ({{F39}}) and `prefers-reduced-motion`.

8. Write `examples/animation/index.html`, which plays `intro` and has a
   reduced-motion toggle. Add the README (model reference, safety rules and
   the GSAP ban), tests and a changeset.

## Acceptance criteria

- [ ] `model.test.js`: `samples/animation.lino` and the step 2 example load
      with no error diagnostics, and unsorted or out-of-range offsets give
      diagnostics.
- [ ] `sample.test.js`: `sample(press-feedback, 75)` gives `scale` 0.96
      under linear easing, and 1000 calls with the same arguments return
      identical results.
- [ ] `effects.test.js`: `decipher` with `seed 42` gives a snapshot-stable
      frame sequence, and `grep -rn "Math.random" packages/ui-animation/src`
      is empty.
- [ ] `easing.test.js`: a spring settles within 0.1 percent of its target by
      `settleTime`, and `toCssLinear` returns a valid `linear(...)` string.
- [ ] `validate.test.js` (regression): `fill both` on `clip-path` is an
      error, and an opacity flicker of `0 → 1` with `(steps 1)` at 8 Hz is a
      flash error. A breathing glow at 0.5 Hz passes.
- [ ] `compile-waapi.test.js`: the `press-feedback` output equals the object
      in step 6.
- [ ] `player.test.js`: with a manual clock and a fake `animate`, `seek(75)`
      and `finished` behave deterministically, and reduced motion switches to
      the reduced variant.
- [ ] Playwright `animation.spec.js` (Chromium): after `panel-enter`
      finishes, the computed `translate` and `clip-path` equal their values
      before the animation, so nothing is left behind.
- [ ] `npm ls gsap` finds nothing.
- [ ] `npm run lint`, `npm run format:check`, `npm run check:duplication` and
      `npm test` pass.
