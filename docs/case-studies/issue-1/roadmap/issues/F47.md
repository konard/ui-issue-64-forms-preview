## Context

Issue #1 asks that it is "easy to explain changes to agents: reconfigure any
UI, then ask an agent to make those settings the defaults" (R12), and that the
description is "sharable by default" (R7). Dev mode ({{F46}}) writes every
change to the `user` or `session` configuration layer. This issue turns those
changes into three hand-off artefacts, as planned in
[`docs/ARCHITECTURE.md`](https://github.com/link-foundation/ui/blob/main/docs/ARCHITECTURE.md)
("Configuration layers and agent hand-off"):

1. an `overrides` LiNo document (the shape of
   [`samples/overrides.lino`](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/samples/overrides.lino)):

   ```lino
   (user-overrides: overrides
     (layer user)
     (base app)
     (set greeting text 'Hello, agents')
     (set material3 token color.primary '#00639B'))
   ```

2. a share URL that carries only that diff;
3. a ready-to-paste instruction that tells an AI agent to apply the patch to
   the committed `site` configuration and open a pull request.

Prior art we already have
([konard.github.io research](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/konard-github-io-and-links-visuals.md)
section 2,
[immortality research](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/immortality-and-anime-avatar.md)
sections 6 and 8.1,
[formal-ai research](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/formal-ai.md)
section 5):

- konard.github.io shares looks as `#settings=<urlencoded JSON>`; opening a
  link applies it, saves the previous look as a "Before the link" preset and
  strips the hash. Only non-default values are stored.
- immortality shares only the diff from defaults (`diffFromDefaults`, version
  tag `v:2`), treats all external configuration as untrusted
  (`mergeSettings` coerces values and drops unknown keys) and keeps the
  viewer's comfort keys (motion, sound, volume) when applying a shared look.
  Its share links are percent-encoded JSON, "long and unreadable".
- formal-ai builds prefilled GitHub issue URLs capped at an 8,192-character
  URL budget.

## Goal

From dev mode a user presses **Make these the defaults** and gets: the
overrides as LiNo text, a share link, and an agent instruction, each with a
Copy button. Opening a share link previews the overrides in the `session`
layer after strict validation.

## Scope

### In scope

- `exportOverrides(config, options)` that produces the `overrides` document
  from the difference between the writable layers (`user`, `session`) and the
  `site` layer, using the patch export of {{F10}}. Deterministic order (by
  element id, then property).
- Share link encode and decode: `#ui-overrides=<percent-encoded LiNo>`.
  If the URL would exceed 8,192 characters the share button is disabled with a
  message to copy the LiNo text instead.
- Untrusted input validation for share links and pasted text (see step 4).
- Applying a share link: decode, validate, show a banner
  "Shared UI changes are previewed. Keep / Discard", write to `session`,
  save the previous `session` and `user` overrides as a "Before the link"
  backup, remove the hash with `history.replaceState`.
- Comfort keys: a site-declared list (for example
  `(comfort-keys motion.mode sound.on sound.volume)`) that shared links never
  change.
- Agent instruction generator from a template file with `{name}` placeholders.
- A "Make these the defaults" dialog in the dev mode inspector with three
  read-only text areas, Copy buttons and an optional "Open as GitHub issue"
  link when the site policy declares a repository.

### Out of scope

- A CLI or bot that applies the patch automatically (a follow-up on top of
  {{F14}}).
- Sharing whole documents or designer output: {{F55}} and {{F48}}.
- Presets, randomisation and the settings schema: {{F15}} and {{F37}}.

## Dependencies

- {{F46}} (blocker): the inspector, the dev mode policy and the place for the
  dialog. Through it, the {{F10}} configuration API (layers, patch export,
  writes to `session`).
- Related: {{F15}} (diff-only sharing of schema settings; reuse its codec if it
  is merged first), {{F14}} (what the agent uses to keep comments when it
  edits the site file), {{F13}} (localised dialog text).

## Step-by-step plan

1. In `packages/ui-devmode/src/export.js` implement
   `exportOverrides(config, { id = 'user-overrides', base, layers = ['user', 'session'] })`
   returning `{ text, links, count }`. `text` is formatted with the official
   `links-notation` formatter and parses back to the same links.
2. Extend the dev mode policy ({{F46}}) with optional keys:

   ```lino
   (site-dev-mode: dev-mode
     (repository link-foundation/ui)
     (site-config site/config/site.lino)
     (comfort-keys motion.mode sound.on sound.volume))
   ```

3. `src/share.js`: `encodeShareHash(text)` returns `'#ui-overrides=' + encodeURIComponent(text)`;
   `decodeShareHash(hash)` returns the text or `null`. `shareUrl(location, text)`
   returns `{ url, tooLong }` with the 8,192-character budget.
4. `src/validate.js`: `validateOverrides(text, { schema, policy })` returns
   `{ links, rejected: [{ link, reason }] }`:
   - parse with `new Parser({ maxInputSize: 65536, maxDepth: 16 })`;
   - exactly one top-level link of type `overrides`;
   - only `layer`, `base` and `set` children; `set` targets an existing element
     or token and a property that the dialect schema allows for its type;
   - values are checked against the property type (length, colour, enum, text);
   - `on` (actions), locked elements and comfort keys are rejected;
   - nothing is ever evaluated; rejected links are reported in the banner.
5. `src/apply-shared.js`: `applySharedOverrides({ config, location, history, storage })`
   implements the flow in scope and returns the report.
6. `src/agent-instruction.txt`: the template. Suggested text:

   ```text
   Make these UI overrides the defaults of {repository}.
   1. Open {siteConfig}. Apply every `set` link below to the matching element
      or token. Keep comments and layout (do not reformat the file).
   2. Do not change anything else. Run: npm test
   3. Open a pull request titled "Make UI overrides the defaults"
      and paste the overrides block into its description.

   {overrides}
   ```

   `renderAgentInstruction({ repository, siteConfig, overrides })` replaces
   the placeholders; a missing value is replaced by a clear `<unknown ...>`
   marker, never by an empty string.

7. `src/defaults-dialog.js`: the dialog (accessible modal dialog with focus
   trap, `Escape` closes, focus returns to the button), three text areas, Copy
   buttons with a fallback to selecting the text when the clipboard API is
   blocked (immortality pattern), an `aria-live` count "N changes".
8. Tests (`node --test`): export of the sample, share round trip, validation
   cases, instruction rendering, apply flow with fake `location`, `history`
   and `storage`.

## Acceptance criteria

- [ ] With the sample document and the two edits from the sample, `exportOverrides`
      returns text that parses to the same links as `samples/overrides.lino`.
- [ ] `decodeShareHash(encodeShareHash(t)) === t` for every fixture, including
      quotes, hex colours and non-ASCII text.
- [ ] `shareUrl` reports `tooLong: true` above 8,192 characters.
- [ ] `validateOverrides` rejects: unknown element, unknown property, wrong
      value type, an `on` link, a comfort key, input over the size limit, a
      depth over the limit; and accepts the sample.
- [ ] Opening the example page with a share hash shows the banner, applies the
      changes to `session` only, keeps a "Before the link" backup and removes
      the hash.
- [ ] The agent instruction for the example contains the repository, the site
      file path and the overrides block, and no unreplaced `{...}` placeholder.
- [ ] Playwright: change a label in dev mode, open the dialog, copy the share
      link, open it in a new page, see the change previewed.
- [ ] The dialog passes axe checks; screenshot attached to the pull request.
- [ ] `npm run lint`, `npm run format:check`, `npm run check:duplication`,
      `npm test` pass.

- konard.github.io `src/settings/presets.js` (`shareLink`, `lookOfHash`,
  `openSharedLook`) and `src/settings/store.js` (diff from defaults).

  `encodeURIComponent` and the Clipboard API.
