## Context

The code is public domain (Unlicense, R25), and our own assets must be public domain too (R26, CC0-1.0 in practice). Third-party icons and assets are allowed, but each one must link to its source and state copyright, licence and attribution (R27). Principle 7 of [`docs/ARCHITECTURE.md`](https://github.com/link-foundation/ui/blob/main/docs/ARCHITECTURE.md) asks for a machine-readable record per third-party asset. The layer table places assets in `assets/` plus `assets.lino`.

Known problem sources found by the research:

- **Remix Icon** moved to a custom "Remix Icon License v1.0" in January 2026; Fedora flagged it as not free, and older versions are Apache-2.0. **SF Symbols, SF Pro and Segoe** have restricted terms and must never be bundled. See sections 6–7 of [existing-solutions.md](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/existing-solutions.md).
- **anime-avatar** problems ([immortality-and-anime-avatar.md](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/immortality-and-anime-avatar.md), sections 4.2 and 7):
  - `ACS_GF2_MMD_MODEL_ARCHIVES` hot-links about 70 proprietary SUNBORN Girls' Frontline 2 archives;
  - the DamagedHelmet model is CC-BY-NC;
  - some licence strings are not identifiers: "See repository" and "CC-ish";
  - prior art: `attributionRequired()` and `AttributionOverlay` (https://github.com/konard/anime-avatar/issues/19).
- **konard.github.io** has no LICENSE file (GitHub reports `license: null`), so nothing may be copied from it until it is relicensed ([konard-github-io-and-links-visuals.md](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/konard-github-io-and-links-visuals.md)).
- **meta-sovereign-chat** draws its icons in `icons.js` from Lucide shapes, which are ISC: permissive, but not public domain ([meta-sovereign-chat.md](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/meta-sovereign-chat.md), "Licensing").

The record format is sketched in [`samples/assets.lino`](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/samples/assets.lino):

```lino
(lucide-check: asset
  (kind icon)
  (source 'https://lucide.dev/icons/check')
  (license ISC)
  (copyright 'Lucide Contributors')
  (notice 'https://github.com/lucide-icons/lucide/blob/main/LICENSE'))
```

## Goal

Make the repository REUSE 3.3 compliant, define the `assets.lino` record format, and add a CI check. The check fails when any file under `assets/` lacks a record, or when a record has a missing or disallowed licence. It also renders attribution text from the records.

## Scope

### In scope

- `REUSE.toml`, plus `LICENSES/` with the texts of every licence in use (Unlicense, CC0-1.0, and each third-party licence).
- `assets/README.md`, `assets/assets.lino` and `assets/links-ui-logo.svg` (our own CC0 placeholder).
- `docs/licensing.md`: the policy, the allow and deny lists, the record format, and the known problem sources above.
- `scripts/check-assets.mjs`: a record per file, licence policy, and `REUSE.toml` kept in sync.
- `scripts/render-attributions.mjs`: generates `assets/ATTRIBUTIONS.md`, and exports a function for later UI use.
- A CI job (a new `.github/workflows/licensing.yml`) that runs both scripts and `reuse lint`.

### Out of scope

- The icon registry and the asset pipeline ({{F36}}), which consume this format.
- The in-app attribution component (part of {{F36}}, or the components issues).
- Relicensing konard.github.io, which the owner must do upstream.

## Step-by-step plan

1. Write `docs/licensing.md`:
   - **Allowed by default:** `Unlicense`, `CC0-1.0`, `MIT`, `ISC`, `BSD-2-Clause`, `BSD-3-Clause`, `Apache-2.0`.
   - **Allowed only as an explicit opt-in**, with an `(opt-in true)` field and attribution: `CC-BY-4.0`, `CC-BY-3.0`, `CC-BY-SA-4.0`.
   - **Denied:**
     - any `*-NC-*` or `*-ND-*` licence;
     - `LicenseRef-*`, unless listed in `docs/licensing.md`;
     - Remix Icon v1.0 or later;
     - SF Symbols, SF Pro and Segoe;
     - unlicensed sources.
   - Add the table of known problem sources from the Context, with the decision for each.
2. Define the record format in `docs/licensing.md`. One link per asset or asset group: `(<id>: asset (field value)...)`.
   - Required fields: `kind` (icon, image, font, sound, model, animation, data), `files` (one or more repository paths or globs under `assets/`, quoted), `license` (an SPDX expression; quote it if it contains spaces) and `copyright` (quoted text, or `none` for our own CC0 assets).
   - Required for third-party assets: `source` (a quoted URL) and `notice` (a quoted URL of the licence text).
   - Optional fields: `attribution` (`required` or `none`), `attribution-text` (quoted), `commercial-use` (`yes` or `no`), `modified` (`yes` or `no`) and `opt-in` (`true`).
3. Create `assets/assets.lino` with a record for `assets/links-ui-logo.svg`: `(license CC0-1.0)`, `(copyright none)`, `(files 'assets/links-ui-logo.svg')`.
4. Implement `scripts/lib/asset-records.mjs` with these functions:
   - `/** @param {string} text @returns {AssetRecord[]} */ parseAssetRecords(text)`. It returns `{id, kind, files, license, copyright, source?, notice?, attribution, attributionText?, commercialUse?, modified?, optIn}`.
   - `/** @returns {{errors: string[]}} */ validateAssetRecords(records, files, policy)`.
5. Implement `scripts/check-assets.mjs`. It must:
   - list the files under `assets/`, except `assets.lino`, `README.md` and `ATTRIBUTIONS.md`;
   - fail if a file matches no record, or more than one record;
   - fail if a record matches no file, or a field is missing;
   - fail if a licence is denied, or opt-in without `(opt-in true)`;
   - fail if a third-party record has no `source`;
   - fail if `REUSE.toml` is not what `--write` would generate.
6. In the same script, generate `REUSE.toml` from the records with `--write`:
   - one `[[annotations]]` block per record, with `path`, `precedence = "aggregate"`, `SPDX-FileCopyrightText` and `SPDX-License-Identifier`;
   - one block that marks the rest of the repository as `Unlicense`, with the copyright "Link Foundation contributors" (check the wording with the maintainer).
7. Implement `scripts/render-attributions.mjs`, exporting `/** @returns {string} */ renderAttributions(records, {format: 'markdown' | 'html' | 'lino'})`. Write `assets/ATTRIBUTIONS.md`, grouped by licence: name, source link, copyright, licence link, attribution text. Records with `(copyright none)` and CC0 are listed as "public domain".
8. Add `LICENSES/Unlicense.txt` and `LICENSES/CC0-1.0.txt` (texts from https://spdx.org/licenses/). `reuse download --all` creates the missing ones.
9. Add `.github/workflows/licensing.yml`, triggered on pull requests and on pushes to main. It runs:
   - `node scripts/check-assets.mjs`;
   - `node scripts/render-attributions.mjs --check`;
   - `pipx run reuse lint` (the `reuse` tool is GPL-3.0; it is used in CI only and never shipped or imported).

   Pin the action SHAs as the other workflows do.

10. Add the tests `tests/asset-records.test.js` and `tests/check-assets.test.js`. Use temp-dir fixtures: a file without a record, a `CC-BY-NC-4.0` record, a Remix Icon `LicenseRef`, a missing `source`, a valid Lucide ISC record, and our own CC0 file.
11. Add npm scripts: `"check:assets": "node scripts/check-assets.mjs"` and `"assets:attributions": "node scripts/render-attributions.mjs"`.

## Acceptance criteria

- [ ] `pipx run reuse lint` reports the repository as compliant.
- [ ] `npm run check:assets` exits 0 on main, and exits 1 (naming the file) when you add `assets/tmp.svg` without a record.
- [ ] The tests reject `CC-BY-NC-4.0`, a Remix Icon `LicenseRef`, opt-in licences without `(opt-in true)`, and third-party records without `source`. They accept Lucide ISC and own CC0 records.
- [ ] `assets/ATTRIBUTIONS.md` is generated, and `render-attributions.mjs --check` fails when it is stale.
- [ ] `docs/licensing.md` lists Remix Icon, SF Symbols/SF Pro/Segoe, the GF2 archives, the CC-BY-NC DamagedHelmet, konard.github.io (no licence) and Lucide (ISC) with a decision for each.
- [ ] The `licensing.yml` workflow is green on the PR. `npm test`, `npm run lint` and `npm run format:check` pass.

## How to verify

```bash
npm ci
npm run check:assets
node scripts/render-attributions.mjs --check
pipx run reuse lint
node --test tests/asset-records.test.js tests/check-assets.test.js
touch assets/tmp.svg && npm run check:assets; echo "exit=$?"; rm assets/tmp.svg   # expect exit=1
```

## Prior art and libraries

- REUSE Specification 3.3 and `REUSE.toml`: https://reuse.software. The tool is GPL-3.0 and is used in CI only.
- SPDX licence list: https://spdx.org/licenses/
- Iconify per-set licence metadata (`license.spdx`, `author`, `url`), the model for our records: https://iconify.design
- ScanCode Toolkit (Apache-2.0), an optional later scan for licence drift.
- anime-avatar `attributionRequired()` and `AttributionOverlay` (https://github.com/konard/anime-avatar/issues/19). Unlike them, we decide attribution from explicit fields, not from licence-string heuristics.
