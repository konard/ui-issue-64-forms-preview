## Context

R14 asks that all classical UI/UX be supported as **themes**, so that earlier
versions of our products, deepcase for example, can be reproduced visually as
nested or tabbed LiNo. Our own projects already contain many looks, but each
one is coded differently:

- **deepcase.** Eight distinct looks are catalogued in
  [deepcase.md](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/deepcase.md),
  section 7. The repositories are Unlicense. Theme values come from Chakra
  (`cssVarPrefix: 'deepCase'`), the Perception `deep` palette and the Deep
  2025 MUI palette.
- **konard.github.io.** Skins `glass`, `liquid` and `futuristic`, a corner
  frame generator, and presets such as Matrix universe and blueprint. The
  repository has **no licence**, so its code must not be copied. Re-implement
  the ideas instead
  ([konard-github-io-and-links-visuals.md](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/konard-github-io-and-links-visuals.md)).
- **immortality** (Unlicense). 12 palettes, 13 surfaces, 9 frame styles and
  12 presets, with Poseidon as the default. konard.github.io ports its
  palettes
  ([immortality-and-anime-avatar.md](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/immortality-and-anime-avatar.md)).
- **formal-ai.** Skins `flat`, `glass` (opacity 0.78), `material` and
  `contrast`; chat styles `cards`, `compact` and `bubbles`; composer styles
  `flat`, `glass-soft`, `glass-clear` and `bubble`. These are orthogonal axes
  combined as root classes
  ([formal-ai.md](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/formal-ai.md)).
- **meta-sovereign.** Chat skins `t3` (default), `telegram`, `whatsapp` and
  `signal`. The bubble radius is 15px, 7.5px and 18px respectively, and the
  skins live in `app.css` around lines 3310–3400
  ([meta-sovereign-chat.md](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/meta-sovereign-chat.md)).

## Goal

Rebuild these looks as theme packages on the {{F39}} engine, as data only:
tokens, style rules, templates and chrome documents. Add a gallery that shows
them side by side in tabs and nested subtrees built with {{F28}}. Every
historical look should be reachable by switching a theme on the same
document.

## Scope

### In scope

Decisions on the eight deepcase looks:

| Look (deepcase.md section 7)           | Decision                                                                   |
| -------------------------------------- | -------------------------------------------------------------------------- |
| 1 classic light 0.1.0-beta             | Theme `deepcase-classic` and chrome document `deepcase-0.1.lino`           |
| 2 dark plus radial menu                | Theme `deepcase-dark`, with `(menu radial)` as the theme's menu preference |
| 3 handler windows                      | Chrome document only (windows from {{F28}}), using `deepcase-dark` tokens  |
| 4 Perception dark                      | Theme `deepcase-perception`                                                |
| 5 deepcase.github.io landing tilt card | Theme tokens only. The tilt animation is out of scope ({{F44}}, {{F62}})   |
| 6 Deep 2025 echarts                    | Theme `deepcase-2025`, with per-value-type colour tokens                   |
| 7 RTS / game mode                      | Out of scope. It is an interaction profile, not a look ({{F62}})           |
| 8 3D / VR force graph                  | Out of scope                                                               |

Other packages:

- konard.github.io, re-implemented: `glass`, `liquid` and `futuristic`, plus
  our own corner-frame style generator (shapes `square`, `cut`, `tall`,
  `wide`, `round`, `scoop` and `notch`; lines `none`, `gap`, `line`,
  `accent` and `bracket`).
- immortality, ported: the 12 palettes as token sets, and the presets
  `poseidon`, `arwes` and `quiet` as themes.
- formal-ai: skins `fa-flat`, `fa-glass`, `fa-material` and `fa-contrast`.
  Chat-style packs `chat-cards`, `chat-compact` and `chat-bubbles`, and
  composer packs, are applied as nested themes on the chat subtree.
- meta-sovereign: chat skins `chat-t3`, `chat-telegram`, `chat-whatsapp` and
  `chat-signal`, each with bubble radius and accent tokens.

### Out of scope

- The graph renderer. Graph styles are defined here as tokens and style rules
  targeting the graph kinds, and {{F34}} and {{F62}} render them.
- Migrating the source apps themselves ({{F58}}, {{F61}}, {{F62}}, {{F64}}).
- Retro desktop themes (Windows 9x, Aqua) and the remaining 9 immortality
  presets. Leave these for follow-up issues.
- Fonts. Any `@fontsource` font is referenced by name only; this issue
  bundles no font files.

## Dependencies

- {{F39}} (blocker). Supplies the theme format, `extends`, nested application,
  modes, contrast pairs and comfort keys.
- {{F28}} (blocker). Supplies tabs, panels and windows for the chrome
  documents and the tabbed gallery.
- Indirect: {{F26}}, the controls in the chrome: button groups, switches and

- Related: {{F27}} (radial menu), {{F30}} (chat kit; chat packs target its

## Step-by-step plan

1. Create `packages/ui-themes/themes/classic/README.md`. It contains a
   **provenance table** with one row per pack: source repository, file or
   issue URL, source licence, and "ported" or "re-implemented".
   konard.github.io rows must say "re-implemented, no code copied". For
   formal-ai and meta-sovereign, check each repository's licence and record
   it.
2. Write `classic/deepcase/` with `classic.lino`, `dark.lino`,
   `perception.lino` and `2025.lino`, using values from deepcase.md sections
   6–7:
   ```lino
   (deepcase-classic: theme
     (extends base)
     (token color.background '#EDF2F7')
     (token color.primary '#0080FF')
     (token color.on-surface '#3A3A3A')
     (mode dark
       (token color.background '#141214')
       (token color.surface-modal '#19202B')
       (token color.on-surface '#EBF8FF')))
   (deepcase-2025: theme
     (extends base)
     (scheme dark)
     (token color.primary '#CCCCCC')
     (token graph.value.string '#81C784')
     (token graph.value.number '#7986CB'))
   ```
   Graph styles are style rules, for example
   `(style (selector (type link-edge)) (stroke (token graph.edge)) (arrow triangle))`,
   so the graph follows the theme. This fixes the deepcase bug class "graph
   styles outside tokens" (deepcase.md section 10).
3. Write `classic/deepcase/deepcase-0.1.lino`. It is a chrome document built
   with {{F26}} and {{F28}}: row 1 is the attached button groups `auth`,
   `space`, `container`, `copy token`, `paste token`, `gql` and `editor`;
   row 2 is the switches `autofocus`, `focus`, `debug`, `types`, `promises`,
   `traveler` and `breadcrumbs`; then a search field and the version label.
   The graph area is a placeholder `(graph-canvas)` element.
4. Write `classic/konard/`.
   - `frames.js` exports `frameStyle({ corner, line, size })`, which returns
     style-rule LiNo using `clip-path` and borders.
   - Write it from the description only, not from `skins.frames.js`.
   - Corner and edge fills must use the same transparency, which avoids
     konard.github.io issue https://github.com/konard/konard.github.io/issues/47.
   - Add `glass.lino`, `liquid.lino` and `futuristic.lino`. `futuristic` has
     no rounded corners by default.
5. Write `classic/immortality/`.
   - `palettes.lino` holds the 12 palettes, ported from `app/src/settings.ts`
     (Unlicense).
   - `poseidon.lino`, `arwes.lino` and `quiet.lino` select a palette, a
     surface and a frame.
   - Glow, scanline and flicker effects respect `(motion reduced)`. No
     effect may flash: the immortality `steps(1)` regression must not come
     back.
6. Write `classic/formal-ai/` with the skins `fa-flat`, `fa-glass`,
   `fa-material` and `fa-contrast`. `fa-glass` has the token
   `surface.opacity 0.78`, and `fa-contrast` uses the {{F39}} high-contrast
   rules. Then write the chat and composer packs.
   - These axes are orthogonal, so each is its own theme applied to a
     subtree, for example `(chat: stack (theme chat-bubbles) ...)`.
   - Never use combined root classes.
   - Every skin must define all tokens the base theme defines (formal-ai bug
     110: "skins should cover the whole UI").
7. Write `classic/meta-sovereign/` with `chat-t3.lino`,
   `chat-telegram.lino`, `chat-whatsapp.lino` and `chat-signal.lino`. Use
   the `token bubble.radius` values above. Filled accents keep 4.5:1 through
   {{F39}} `pair` checks, as in meta-sovereign's delivery audit.
8. In `examples/themes/classic.html`, build the gallery: one {{F28}} tab per
   family, and inside the deepcase tab a nested subtree that switches between
   the four deepcase themes. Add Playwright screenshots, tests and a
   changeset.

## Acceptance criteria

- [ ] `classic-load.test.js`: every `.lino` file under `themes/classic/`
      parses and loads with no error diagnostics, and every `pair` passes in
      every declared mode.
- [ ] `classic-coverage.test.js`: every skin defines every semantic token
      that `base` defines, so no element is left unthemed.
- [ ] `classic-frames.test.js`: `frameStyle` output for all 7 shapes × 5
      lines matches snapshots, and corner and edge opacity are equal (the
      issue 47 regression).
- [ ] `classic-provenance.test.js`: every pack has a provenance row, and no
      row for konard.github.io says "ported".
- [ ] `deepcase-0.1.lino` renders the two control rows and the search field
      in the {{F28}} layout, and switching between `deepcase-classic` and
      `deepcase-dark` creates no new DOM nodes.
- [ ] Glow, flicker and scanline styles contain no `steps(1)` animation, and
      they are disabled under `(motion reduced)`.
- [ ] Gallery screenshots for every pack are attached to the pull request,
      with a side-by-side comparison against deepcase-app issue 76 and
      deepcase-app issue 299 screenshots for looks 1 and 2.
- [ ] `npm run lint`, `npm run format:check`, `npm run check:duplication` and
      `npm test` pass.
