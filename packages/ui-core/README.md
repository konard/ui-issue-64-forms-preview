# @link-foundation/ui-core

Core of the associative UI framework [`link-foundation/ui`](https://github.com/link-foundation/ui).

This package is the workspace skeleton. It exports only the version of the UI
dialect of Links Notation:

```js
import { UI_DIALECT_VERSION } from '@link-foundation/ui-core';

console.log(UI_DIALECT_VERSION); // 'ui-dialect/0'
```

The real core is described in
[`docs/ARCHITECTURE.md`](https://github.com/link-foundation/ui/blob/main/docs/ARCHITECTURE.md).
