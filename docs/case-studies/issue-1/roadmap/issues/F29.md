## Context

Chat lists, message streams, the designer outline, settings lists and data
tables all need to show many items quickly and accessibly. Our projects already
contain good parts we should keep in one place:

- meta-sovereign `js/src/web/chat-list-window.js` is a measured virtual list
  modelled on the telegram-tt `viewportIds` idea: it keeps `listOffsets`, finds
  the first visible row with a binary-search `indexAt`, and computes
  `listRange` with one screen of overscan. It also uses CSS
  `content-visibility: auto` with `contain-intrinsic-size`
  ([research](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/meta-sovereign-chat.md)).
- immortality has `DataTable` as the accessible twin of every chart
  ([research](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/immortality-and-anime-avatar.md)).
- deepcase has no pagination of large results
  (https://github.com/deep-foundation/deepcase/issues/36,
  [research](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/deepcase.md)).
- formal-ai has a sidebar where mouse-wheel scrolling breaks
  (https://github.com/link-assistant/formal-ai/issues/447,
  [research](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/formal-ai.md)).

## Goal

`@link-foundation/ui-components` provides `list`, `tree` and `table` elements
described in Links Notation, with a shared virtualisation core that handles
variable item heights, keyboard navigation and screen readers, and that is
reused by the chat kit ({{F30}}).

## Scope

### In scope

- `virtual-range.js`: the pure measured-virtualisation core (offsets, binary
  search, overscan, anchor preservation on prepend).
- `list` (single and multi selection, APG listbox pattern, virtualised
  option, item template).
- `tree` (APG tree view: expand, collapse, typeahead, lazy children).
- `table` (APG grid pattern: sortable columns, column resize, sticky header,
  row selection, virtualised rows, accessible caption).
- Empty, loading and error states for all three.

### Out of scope

- Message timeline logic (load older and newer, jump, stick-to-bottom); that
  is {{F30}}, built on the core from this issue.
- Editable cells and spreadsheet formulas.
- Charts ({{F31}}).

## Dependencies

- **Blocked by {{F25}}**: we consume the behaviour state machines (selection,
  roving focus, typeahead) and the action registry, so `on select` and
  `on activate` handlers come from LiNo. To start early, write
  `virtual-range.js` and the sort and selection models as pure functions; the
  elements can wait for {{F25}}.
- **Related:** {{F08}} (the store that feeds `items $chats`), {{F28}} (lists
  live inside split panes), {{F30}} (uses the virtual core), {{F37}} (the
  settings panel may use `list`), {{F46}} (the dev-mode outline uses `tree`).

## Step-by-step plan

1. Create `packages/ui-components/src/data/` and export it from
   `packages/ui-components/src/index.js`.
2. Write `virtual-range.js`:
   ```js
   /**
    * @param {{ count: number, estimate: number, measured: Map<number, number> }} input
    * @returns {Float64Array} offsets, length count + 1
    */
   export function listOffsets(input) {}
   /** @returns {number} index of the item that contains `y` (binary search) */
   export function indexAt(offsets, y) {}
   /**
    * @returns {{ start: number, end: number }} with one viewport of overscan
    */
   export function listRange(
     offsets,
     scrollTop,
     viewportHeight,
     overscan = 1
   ) {}
   /** keeps the item under the anchor in place after items are prepended */
   export function anchorScrollTop(before, after, anchorKey) {}
   ```
   Port the idea from meta-sovereign `chat-list-window.js` (Unlicense) with
   tests `virtual-range.test.js` for 0, 1, 10 and 100 000 items.
3. Measure rows with one shared `ResizeObserver` whose callback is deferred to
   `requestAnimationFrame` (meta-sovereign avoided a WebKit loop this way).
4. Write `selection-model.js` (single, multi, range with Shift, toggle with
   Ctrl or Cmd) and `sort-model.js` (stable sort, ascending, descending, none).
5. Write the elements `list.js`, `tree.js` and `table.js` on top of {{F16}}
   and {{F25}}. The DOM keeps the focused item rendered even when it is out of
   range, so the screen reader focus is never lost; set `aria-setsize` and
   `aria-posinset` on rendered rows.
6. Wheel, touch and keyboard scrolling must all work inside nested scroll
   containers (regression test for formal-ai issue 447).
7. Add `packages/ui-components/examples/data.html` with a 100 000-row list, a
   2 000-node tree and a 10 000-row table.

Input example (working names; the dialect is fixed in {{F03}}):

```lino
(chat-list: list
  (virtualized true)
  (item-height 3.5rem)
  (items $chats)
  (template chat-row)
  (selection single)
  (on select (navigate chat (id $item.id))))
(people: table
  (caption 'People')
  (items $people)
  (columns
    (name: column (label 'Name') (sortable true))
    (age: column (label 'Age') (align end) (sortable true)))
  (virtualized true))
```

## Acceptance criteria

- [ ] `virtual-range.test.js` covers empty lists, variable heights, overscan
      and anchor preservation, and passes.
- [ ] With 100 000 items, fewer than 200 row elements are in the DOM at any
      time (Playwright counts them).
- [ ] Prepending 50 items keeps the visible row at the same screen position
      (Playwright, tolerance 1 px).
- [ ] `list`, `tree` and `table` pass the APG keyboard interactions for
      listbox, tree view and grid (Playwright tests list the keys used).
- [ ] Sorting a table column sets `aria-sort` and the order is stable (test).
- [ ] Mouse wheel scrolling works in a list nested inside a scrolling sidebar
      (Playwright, regression for formal-ai issue 447).
- [ ] axe reports no violations on `examples/data.html`.

## How to verify

```bash
node --test packages/ui-components/tests/data/*.test.js
npx playwright test packages/ui-components/tests/e2e/data.spec.js
npm run lint && npm run format:check && npm run check:duplication
```

Expected screenshots: the list scrolled to item 50 000 with correct row
contents, the tree with three levels expanded, and the table sorted by age with
the sort arrow visible.

## Prior art and libraries

- meta-sovereign `chat-list-window.js` (Unlicense, port the algorithm).

  meta-sovereign research.

  their repositories; they are not in our research, so check the licence and
  the current version). They are a good reference for the API; adopt them only
  if our own core cannot reach the criteria.
