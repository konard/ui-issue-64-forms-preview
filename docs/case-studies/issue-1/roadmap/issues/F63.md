## Context

[anime-avatar](https://github.com/konard/anime-avatar) is "Avatar Studio". It
loads, poses, animates, lights and exports VRM, glTF, FBX and MMD characters
in the browser. The code is Unlicense; third-party models are under their own
terms. The facts below come from the
[research](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/immortality-and-anime-avatar.md).

The studio lives in `public/studio/` and has no build step:

- React 18 UMD and Babel standalone are loaded from unpkg, so JSX is
  transpiled in the browser on every load, using the development React
  build.
- An importmap pins `three@0.160.0` and `@pixiv/three-vrm@2.1.1`.
- Dependencies come from the CDN without SRI.
- Modules publish `window.ACS_*` globals.

It has no settings schema:

- `defaults.js` holds about 150 flat keys.
- `Editor.jsx` (2,381 lines, 22 sections) wires every control by hand, using
  `Studio.Section/Row/Slider/ColorPick/Select/Chips/Toggle` from `ui.jsx`.
- `randomizers.js` repeats the ranges.
- The config is stored in localStorage key `acs_B`.
- Import does `{...DEFAULTS, ...JSON.parse(text)}` and reports errors with
  `alert`.

Licensing risk:

- `ACS_GF2_MMD_MODEL_ARCHIVES` hot-links about 70 proprietary SUNBORN Girls'
  Frontline 2 archives.
- The DamagedHelmet sample is CC-BY-NC 4.0, so it is non-commercial.
- Labels such as "CC-ish" and "See repository" are not licence identifiers.

## Goal

The studio has a build step and pinned dependencies with no globals. Its
settings come from a LiNo schema rendered by the {{F37}} panel, and it can
record and replay a posing session with {{F45}}. Every model entry has a
licence record. Proprietary and non-commercial assets are excluded from
the defaults, or offered only behind an explicit opt-in that shows the terms.

## Scope

### In scope

The inventory and mapping (paths are under `public/studio/` unless noted):

| Old piece                                                                                 | Framework piece or action                                                         |
| ----------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| `index.html` (unpkg React UMD, Babel standalone, importmap)                               | bundled build, pinned npm deps; delete Babel standalone                           |
| `defaults.js` (`window.ACS_DEFAULTS`, about 150 keys)                                     | `settings.lino` schema for {{F15}}, with `vector3`, `map`, `color`, `asset` kinds |
| `Editor.jsx` (22 sections) + `ui.jsx` (Studio kit)                                        | {{F37}} generated panel; per-section randomize/reset                              |
| `randomizers.js`, `ACS_BONE_LIMITS`                                                       | schema constraints; {{F15}} randomize with locks                                  |
| `App.jsx` (`acs_B`, `?view=`, `window.__acs`)                                             | {{F08}} store, versioned key, LiNo import/export; dev handle via {{F46}}          |
| `acs-config.json` export/import                                                           | LiNo `(cfg (version 1) ...)` plus a JSON reader for old files                     |
| `constants.js` `ACS_MODEL_PRESETS`, `ACS_ANIMATION_PRESETS`, `ACS_GF2_MMD_MODEL_ARCHIVES` | asset records ({{F36}} format) with SPDX or `LicenseRef-*`                        |
| `AttributionOverlay`, `attributionRequired` (`Editor.jsx`)                                | framework attribution component (open an issue if {{F36}} lacks it)               |
| `gestures.js`, `ACS_EASINGS`, `textMotion.js`                                             | {{F44}} easing catalog; {{F45}} recording of pose and gesture changes             |

### Out of scope

- The three.js engine, the retargeting (`animations.js`) and the AI features
  (`ipaSpeech.js`, `textToModel.js`, `gearSonic.js`).
- The archived Vite app in `src/` (reference only).
- The open feature requests konard/anime-avatar#18, konard/anime-avatar#21 to konard/anime-avatar#24 and konard/anime-avatar#38.

## Dependencies

- **Blocked by {{F37}}**: a panel generated from a LiNo schema, with groups,
  sliders with units, colour pickers, chips, and per-group randomize and
  reset. Ask {{F15}} for the `vector3`, `map` and `asset` kinds if they are
  missing.
- **Blocked by {{F45}}**: the recorder and replay. Pose, expression and
  gesture changes become a LiNo timeline, for example
  `(at 1.2 (play gesture wave (mood happy)))`.
- **Related:** {{F57}} (playbook), {{F15}}, {{F36}} (asset records), {{F44}},
  {{F46}}, {{F64}} (the same panel and schema engine).
- A stub is possible: steps 1–5 (licence audit, build step, contracts) need
  no framework code.

## Step-by-step plan

1. Copy the {{F57}} checklist template into the tracking pull request.
2. **Licence audit first.** For every entry in `ACS_MODEL_PRESETS`,
   `ACS_ANIMATION_PRESETS` and `ACS_GF2_MMD_MODEL_ARCHIVES`, write an asset
   record:
   ```lino
   (damaged-helmet: asset (kind model) (format gltf)
     (source 'https://github.com/KhronosGroup/glTF-Sample-Models')
     (license CC-BY-NC-4.0) (commercial false) (attribution required))
   ```
   Check each URL; the one above is an example. Move the GF2 archives and the
   non-commercial assets out of the default list, behind an opt-in dialog
   that shows the terms. Replace "CC-ish" and "See repository" with real
   identifiers, or with `LicenseRef-unknown` and a warning.
3. **Freeze the contracts.** Add tests that check:
   - an old `acs_B` value and an old `acs-config.json` load to the same cfg;
   - `?view=editor|tests|split|none` works;
   - `window.__acs.probe` still answers, for the in-app tests.
4. **Baseline screenshots** using the existing canvas fingerprint and
   `probeDiff`. Cover 3 presets × editor open/closed × desktop/mobile.
5. **Build step.** Add Vite, or the framework's recommended bundler, and
   install `react`, `three@0.160.0` and `@pixiv/three-vrm@2.1.1` from npm.
   Remove Babel standalone and the unpkg URLs, and replace the `window.ACS_*`
   globals with ES module imports. Keep `public/studio/` paths working for
   GitHub Pages.
6. **Schema.** Generate `public/studio/settings.lino` from `defaults.js` and
   the ranges in `Editor.jsx`. Example:
   `(look.smoothing: (type range) (default 0.15) (min 0) (max 1) (step 0.01))`,
   with the real values taken from the code. Bones use `vector3` with
   `ACS_BONE_LIMITS` in degrees (konard/anime-avatar#28 asked for anatomical
   ranges in degrees).
7. **Panel.** Render the 22 sections with {{F37}} one section at a time.
   Delete the hand-written JSX for each section once its screenshot matches.
8. **Storage.** Use a versioned key, import that validates and coerces
   values (unknown keys dropped), and in-panel error messages instead of
   `alert`.
9. **Recording.** Wire {{F45}} so a posing session can be recorded, saved as
   `.lino` and replayed. Gestures add to look-at instead of replacing it
   (konard/anime-avatar#28).
10. **Delete** the replaced code and record the line counts of `Editor.jsx`
    and `randomizers.js` before and after.

## Acceptance criteria

- [ ] `grep -rn "unpkg.com\|babel" public/index.html` returns nothing.
- [ ] Every model and animation preset has a licence record; a test fails on
      a missing `license` or a non-SPDX value without the `LicenseRef-`
      prefix.
- [ ] The default model list contains no GF2 archive and no `NC` licence
      (test).
- [ ] An old `acs_B` value and an old `acs-config.json` load correctly
      (tests).
- [ ] All 22 sections render from `settings.lino`, and randomize/reset work
      per section.
- [ ] A recorded 10 s session replays with the same final cfg (test compares
      the cfg diff).
- [ ] `Editor.jsx` is under 1,500 lines.

## How to verify

```bash
npm ci && npm test
npm run build && npx playwright test
grep -c "license" public/studio/assets.lino
wc -l public/studio/Editor.jsx public/studio/randomizers.js
```

Open the studio, record a gesture, reload, replay it, and compare it with the
baseline fingerprints.
