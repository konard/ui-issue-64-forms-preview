## Context

R19 asks for React and React Native. Today every iOS and Android build of our
projects is a Capacitor WebView; there are no React Native apps yet
([ui-projects-inventory.md](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/ui-projects-inventory.md)
section 4). The research recommends a React Native renderer on the New
Architecture only (React Native 0.82, October 2025, can no longer enable the
legacy architecture), Expo SDK 54+ for demos and React Native Web to show the
result on the docs site
([existing-solutions.md](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/existing-solutions.md)
section 8 and Recommendations A.8). lino-i18n already has a
`react-native-web` example
([ui-projects-inventory.md](https://github.com/link-foundation/ui/blob/main/docs/case-studies/issue-1/research/ui-projects-inventory.md)
section 2.3).

There is no DOM on React Native, so `ui-dom` ({{F16}}) cannot be reused.
Instead this package maps dialect elements to React Native primitives and
reuses the DOM-free hooks of `ui-react` ({{F18}}).

## Goal

Publish `@link-foundation/ui-react-native` with a `<UiNativeView>` component
that renders a UI dialect document with `View`, `Text`, `Pressable`,
`Image` and `ScrollView`, updates incrementally from the store, dispatches
actions by name and uses the link ID as `testID`.

## Scope

### In scope

- A pure mapping function from a store element to a primitive description,
  testable with `node --test` without React Native installed.
- `<UiNativeView source | store, actions, onAction, components />`.
- Kinds: `document`, `stack`, `text`, `button`, `image`; unknown kinds render
  a `View` with a development warning.
- Style conversion from resolved declarations (from {{F12}}) and token values
  (from {{F11}}) to React Native style objects.
- Accessibility props: `accessibilityRole`, `accessibilityLabel`,
  `accessibilityState` for disabled buttons.
- An Expo example app that also runs on the web through React Native Web.

### Out of scope

- Full control set and state machines on native (follow-up after {{F25}} and
  {{F26}}; the machines are DOM-free, so wiring them here is a later issue).
- Native modules, navigation libraries, animations ({{F44}}).
- Supporting the legacy architecture or React Native versions below 0.82.

## Dependencies

- {{F18}} (blocker): the DOM-free entry `@link-foundation/ui-react/hooks`
  (`useUiStore`, `useUiElement`, `useUiProp`, `useUiAction`) and the provider
  and action contract (`{ source, event, action }` detail).
- Indirect: {{F08}} store, {{F06}} `parse`, {{F11}} token values (use the JS
  or JSON output, not CSS), {{F12}} resolved declarations per element.
- Related: {{F03}} fixtures (render tree snapshots shared with {{F22}} and
  {{F24}}), {{F25}}, {{F26}}, {{F54}} (docs site embeds the web build).
- To start before F12 merges, accept `styles` as a plain
  `{ [id]: { padding: '16px' } }` object.

## Step-by-step plan

1. Create `packages/ui-react-native/package.json`: name
   `@link-foundation/ui-react-native`, `"type": "module"`,
   `peerDependencies` `react` and `react-native` `>=0.82` (check the current
   version). Dependencies: `@link-foundation/ui-react` (hooks entry only),
   `@link-foundation/ui-store`, `@link-foundation/ui-core`.
2. `src/map.js`, no React Native import:

   ```js
   /**
    * @typedef {{ type: 'View'|'Text'|'Pressable'|'Image'|'ScrollView', props: object,
    *   children: (NativeNode|string)[] }} NativeNode
    * @param {UiNode} node
    * @param {{ styles: object, tokens: object, warn: (msg: string) => void }} ctx
    * @returns {NativeNode}
    */
   export function mapElement(node, ctx) {}
   ```

   Mapping table:

   | Kind       | Primitive                       | Notes                                       |
   | ---------- | ------------------------------- | ------------------------------------------- |
   | `document` | `ScrollView`                    | `title` ignored                             |
   | `stack`    | `View`                          | `flexDirection` from `direction`, `gap`     |
   | `text`     | `Text`                          | first value is the string                   |
   | `button`   | `Pressable` with a `Text` child | `accessibilityRole: 'button'`, `disabled`   |
   | `image`    | `Image`                         | `source: { uri }`, `accessibilityLabel` alt |
   | other      | `View`                          | `ctx.warn('unknown kind ...')`              |

   Every node gets `testID: node.id` when the element has an ID.

3. `src/style.js`: `toNativeStyle(declarations, tokens)`; convert `'16px'` to
   `16`, resolve `(token space.medium)` through the tokens object, map
   `radius` to `borderRadius`, `background` to `backgroundColor`; drop
   unsupported properties with a warning list returned for tests.
4. `src/UiNativeView.js`: a component that walks the store tree; each element
   is rendered by a memoised `Element` component that subscribes with
   `useUiElement(id)`, so a prop change re-renders only that element.
   `createElement` uses primitives injected from `react-native`, which lets
   tests pass fakes.
5. Actions: `onPress` of a `button` builds the same detail as {{F16}}
   (`{ source: 'ok', event: 'press', action: ['navigate', 'home'] }`), calls
   `onAction` and the named handler. Never evaluate strings.
6. `components` prop: `{ chart: MyChart }` renders the given React Native
   component for that kind with `{ id }`.
7. Example `examples/react-native/` (Expo, check the current SDK version):
   renders `docs/case-studies/issue-1/samples/document.lino`; `npx expo export --platform web`
   builds a static web version through React Native Web.
8. Tests (below), README, changeset.

## Files to create or change

- `.changeset/<name>.md`

Expected `mapElement` output for `(ok: button (label 'OK'))`:

```js
{ type: 'Pressable', props: { testID: 'ok', accessibilityRole: 'button', disabled: false },
  children: [{ type: 'Text', props: {}, children: ['OK'] }] }
```

## Acceptance criteria

- [ ] `map.test.js`: every row of the mapping table has a test; unknown kinds
      call `warn` once and return a `View`.
- [ ] `map.test.js` renders `samples/document.lino` to a `NativeNode` tree
      equal to `tests/__snapshots__/document.native.json`; every element with
      an ID has a matching `testID`.
- [ ] `style.test.js`: `'16px'` becomes `16`, a token reference resolves to
      its value, `'#6750A4'` stays a string, unsupported properties are
      reported.
- [ ] `view.test.js`: a store change to `greeting` re-renders only the
      `greeting` element (render counter per element).
- [ ] `actions.test.js`: pressing `ok` calls `onAction` with the F16 detail
      and the named handler; `'alert(1)'` as a value is never executed
      (`grep -rE "eval\(|new Function" packages/ui-react-native/src` is empty).
- [ ] The package imports nothing from `react-dom` or `ui-dom` (test or lint
      rule).
- [ ] `npx expo export --platform web` in `examples/react-native` succeeds and
      a screenshot of the web build is attached to the pull request.
- [ ] `npm run lint`, `npm run format:check`, `npm run check:duplication` and
      `npm test` pass.

## How to verify

```bash
npm install
node --test packages/ui-react-native/tests/*.test.js
cd examples/react-native && npm install && npx expo export --platform web
npx serve dist   # open in a browser, take a screenshot
```

Optional: run the example on a device or simulator with Expo Go and attach a
screenshot.
